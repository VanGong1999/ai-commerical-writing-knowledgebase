# 迷蒙爆款流水线与变现七途
> 来源：迷蒙写作课程 / 全课程核心精华 + 全课程知识体系（讲师李白，22 课）
> 权威级别：P1
> 关联 Skills：—
> 关联 Agents：WritingOrchestrator

## 一句话
爆款 = 自我表达 × 用户需求（人性十大元素做底层）；用 40 个模板沿「选题 → 标题 → 开头 → 结构 → 结尾 → 金句 / 故事」流水线生产，再用 7 种途径变现。

## 终极命题与底层思维
- **写作不靠天赋 / 文笔 / 灵感，靠套路**；零基础也能月入过万（课程口径）。
- 新媒体传播的本质是**情绪**，不是文笔。
- 高手与普通人的差距：**掌握套路的多少**（不是 1 万小时）。
- 最高效学习法：**直接拆爆款**，不看书绕路（像研究高考题一样研究爆款）。
- 万能交集：**自我表达 × 用户需求**（不迎合、不日记、不自嗨）。

### 十大爆款元素（底层，价值百万）
| 三大感情 | 五种情绪 | 两大因素 |
|---|---|---|
| 爱情、友情、亲情 | 愤怒、怀旧、暖心、愧疚、孤独 | 地域、群体 |

> 内容在变、承载形式在变，但**人性和人心没变**。

## 爆款生产流水线
```
选题（80%）→ 标题（1 秒打开）→ 开头（3 句话留人）→ 结构（效率 + 顺畅）→ 结尾（点赞转发）→ 金句 / 故事（传播发酵）
```

### 选题：三大阶梯
| 阶梯 | 目标 | 方法 |
|---|---|---|
| 一 | 快速 10w+ | 4 套路：改编、盘点梳理、复制高赞评论、从争议点找角度 |
| 二 | 稳上 10w+ | 公式 = **热点 + 十大元素** |
| 三 | 100w+ | 换角色、硬组合、小见大 |

- 选题占爆款 **80%**；热点是通往 10w+ 的**最短路径**。
- **爆款相伴而生**——爆款是「发现」出来的（组合已验证的爆款元素），不是凭空捏造。
- 8 种搜集法：常规 4（微博热搜、新榜排行、新媒体人社群、抖音）+ 秘密武器 3（先知 APP、即刻 / 极客 APP、知音读者旧杂志）。
- 观众只关心自己（前任 3 > 妖猫传）。

### 标题：两步 + 8 模板 + SOP
- **两步**：找敏感词（微信指数 / 大号标题重合词）→ 套模板。
- **8 模板**：数字法、对比法（一边…一边）、热词法、疑问法（核心反常识）、对话法、好奇法、俗语法（押韵）、电影台词法。
- **三大误区**：过长、信息过多不聚焦、等同概括内容。
- **SOP 四步**：套模板出 10~15 个 → 自测选 5 个 → 粉丝群投票 → 数据分析定标题。
- 建标题库 3 法：表格法、定位相似大号、畅销书书名目录。

### 开头：8 模板（三句话留人）
问句式、对话式、互动式、自我表达式、题文呼应式、名人名言式（解构名言）、热点式、粉丝投稿式。

### 结构：4 模板
观点 + N 事例 / 大观点 + N 小观点 / 观点 + N 角度 / 观点 + 人物 N 故事。

### 结尾：4 模板（峰终定律）
总结型、关联读者型、名人名言式、排比式。结尾是离**点赞和互动**最近的地方。

### 金句：7 模板
| 模板 | 核心 |
|---|---|
| 1221 式 | 两词位置相反 + 前后反差 |
| 1213 式 | 共同词 + 核心词相反 / 递进 |
| 搜词法 | 核心词搜同字词组合 |
| 猜字法 | 拆字赋予意义 |
| 具象法 | 抽象变具体画面 |
| 否定法 | 否定常识（全否 / 否半句） |
| 扩字法 | 在句子上扩充改变意思 |

### 故事：4 + 3 + 2 模板
- **四步搞定**：一句话、定冲突、给理由、来组合（**冲突是灵魂**）。
- **三步完善**：交代背景、补充信息、触发情绪爆点。
- **两招引爆**：打乱顺序（倒叙插叙）、场景演绎（画面感）。

## 变现 7 途径
| 途径 | 关键动作 |
|---|---|
| 投稿 | 看 10 篇历史文章；邮件标题加「投稿」 |
| 朋友圈卖货 | 自己先用、是受益者 |
| 写软文 | 购买环境 + 商品故事 + 完读率 |
| 付费内容沉淀 | 知识星球 |
| 开设写作课 | 千聊 |
| 出书 | 简书；书名占 80% |
| 一对一咨询 | 在行 |

## 必背法则（10 条精华）
1. 你和 10w+ 之间只差一个**选题**（占 80%）。
2. 热点是 10w+ 最短路径。
3. 爆款相伴而生，是发现出来的。
4. 标题唯一目的：**1 秒内让读者打开**。
5. 开头三句话留不住读者，文章就废了。
6. 结尾是离点赞互动最近的地方（峰终定律）。
7. **冲突是故事的灵魂**。
8. 新媒体传播的本质是情绪。
9. 少就是多，标题只聚焦**一个爆点**。
10. 一切方法底层：自我表达 × 用户需求。

> 万能公式：**爆款 = 用户思维（自我表达 × 用户需求）+ 热点 × 十大元素 + 40 模板 + 情绪。**

## 可执行清单
- 选题先用「热点 + 十大元素」自检；不确定就拆 3 篇同题材爆款。
- 标题按 SOP：套 8 模板出 10~15 个，自测留 5 个，投票定 1 个，只聚焦一个爆点。
- 开头写满三句话留人测试；结构套 4 模板之一；结尾用峰终定律收互动。
- 金句用 7 模板之一提炼一句可截图传播的句子。
- 变现选一条主路径，先跑通再叠加。

## 反模式
- 自嗨无用户（写日记、只表达自己不满足需求）。
- 标题信息过多、等同概括全文。
- 只看书不拆爆款，绕远路。
- 追求文笔忽略情绪（本末倒置）。

## 与其他课差异（若有）
- **偏公众号 / 新媒体单篇爆文**；网文、短剧、漫剧另遵垂直课（九格 / 查理等）的结构规范。
- 十大爆款元素与查理「需求三级框架」都落人性底层，但迷蒙用于「单篇选题」，查理用于「账号定位」，用途不同。
- 故事 4+3+2 与北大「故事 = 意外」互补：迷蒙给「单篇小故事」模板，北大给「长篇叙事结构」。
