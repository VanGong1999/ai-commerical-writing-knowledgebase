# 短剧拉片原则（个案方法论）
> 来源：查理短剧课 / 5.3·5.4 加餐拉片（原则蒸馏；不对标版权剧情细抄）
> 权威级别：P0
> 关联 Skills：struct.beat20, cool.*, qc.gender_path
> 关联 Agents：WritingOrchestrator, Beat20

## 一句话
拉片学的是「可升级流水线 + 六维抓手」，不是复述某部剧的集数剧情；男女频各有专属抓手——男频满级号「复仇期待 + 造物主赐福双轨 + 量化升级」，女频闪婚霸总「女主画像 × 善良因果 × 观众开天眼信息差」。

## 1. 拉片目的与心态
- 选片：先极致爽感产品（男满级号下山 / 女闪婚霸总类），再扩亲情向、逆袭、单元等。
- 尬感正常：你不是充值人群也会觉得尬——目标是**同爽点拍得更不尬**，勿清高否定模型。否定爽点 = 离开付费赛道。
- 壳不同（都市修仙/古装…）模型可同构；别被赛道名骗。无双/腾龙/紫气东来/凡人修仙记，壳不同、模型高度同构。

## 2. 通用拉片六维（男女通用检查）
1. **爽点主轨**：前 10–20 集拉什么期待（复仇/掉马/因果回报）？
2. **双轨或加码**：除打脸外还有没有「赐福/造物主」或善良因果轨？
3. **量化与阶梯**：对手/修为/地位是否可阶梯升级，避免同质重复？
4. **信息差**：观众是否开天眼？角色蒙在鼓里是否服务于看热闹？
5. **场景经济**：宴会/嘴炮/解说是否用预算约束下的必要技法（可学边界）？
6. **终局交付**：最后十集是否在大团圆上继续加码，而非空转？

## 3. 男频抓手（原则级）
- 前段核心任务：**拉满复仇期待**服务充值点（前 10–20 集）。
- 模型升级：旧「见神杀神」→ 常见 **灭一半收一半** + 扮演造物主（治病/提修为/收小弟一起拽）。
- 外部弱点可反复用（家人被辱）；宴会是省钱大场面工厂——打脸分层、小弟代打。
- 修为量化像游戏（125 vs 110）：懒时好用；高级片要升级威胁逻辑（新神器/新对手），勿只会加数值。
- 男频心理模型（内置代入「县城男人」）：被女方家瞧不起扫地出门 → 自己其实最强 → 救家人治病 → 让首富/长官奉为座上宾 → 打脸轻视者 → 培养更强女配气死前妻 → 鉴宝炼丹收徒操纵势力（造物主快感）。

### 满级号六维升级（创新作业，勿照抄爆款）
| # | 升级维 | 本片通病 | 改进方向 |
|---|---|---|---|
| 1 | 下山目标 | 「了心结」不紧迫不具体无步骤 | 目标加强、可拆步骤、更吸引人 |
| 2 | 权力体系 | 名字多但难感谁强谁弱 | 借传统文化/神话中有代入感的层级体系 |
| 3 | 危机阶梯 | 中段炼丹赛危机下台阶 | 技巧戏最多占 1–2 集；危机阶梯上升；可结合痛感（失误/两难） |
| 4 | 上帝爽感类型 | 只有炼丹/鉴宝/治病 | 救世主可做之事很多（止旱/改命运/点化路人），勿单调 |
| 5 | 报仇现实感 | 修仙皮缺真实人物关系 | 满级回乡：势利亲戚、旧同学等现实羞辱源拉满 |
| 6 | 大结构目标 | 上来预告选弟子，结尾还是选弟子 | 中段应改变/升级终点目标（大结构理论），勿直线不变 |

## 4. 女频抓手（原则级）
- 先齐**女主画像元件**并对准用户画像；因果报应与观众全知是常见引擎。
- 办事路径：**借势/借男人之手**，避免女主天天亲自武力流水线（易跑偏）。
- 自检：充值段是否重复旧梗、Boss 是否过晚过弱、同一功能人物是否复读、迷药/偷听是否滥用。

### 女主画像六元件（极致女频第一课）
| 元件 | 作用 |
|---|---|
| 学历偏低 | 共鸣「不尽如人意」 |
| 婚前不良性行为及后果（未婚先孕） | 软肋可被攻击，也可被「非自愿/下药」圆，化解即爽 |
| 家庭不幸福、被逼婚 | 外部压力 |
| 善良 | 获爱因果核心 |
| 有才华 | 职场逆袭与「靠自己」遮羞布 |
| 勤俭持家、不爱钱 | 通过奶奶/生活考验 |

画像准 → 爽点自动准（总裁钱给我、事事向着我、全家喜欢我、旧过往巧妙化解）。

### 闪婚型女频一句话公式
> 随便找个男人嫁了 → 他竟是真命天子 + 最有钱 + 最有才 + 最霸道 + 与我渊源最深 + 马甲藏不住。

### 女频可加强/创新三点
| # | 问题 | 加强方向 |
|---|---|---|
| 1 | 逻辑瑕疵易出戏 | 藏身份手法要高明（已知是陆少却长期想不到是总裁） |
| 2 | 对手攻击频率与强度无阶梯 | 姑姑出晚、放大招就下药；应让虐心/心痛/着急递进 |
| 3 | 梗重复 | 偷听、迷药、奶奶≈孙子同套路——扩梗库，同一梗少玩几回 |

## 5. 输出规范（禁止事项）
- 产出：模型名、节拍功能表、可迁移手法、雷区——**不写逐集剧情抄本**。
- 对标片名仅作课内学习索引；落地创作须合规换元，尊重版权与审查。

## 可执行清单
```text
选定对标类型 → 静音/跳看标「功能拍」非台词
→ 填六维表 → 标前 20 集期待主轨与充值拐点
→ 写「升级点」3 条（比原片更不尬/更省/更合规）
→ GenderPath + Beat20 对照自检
```
- 男频：数清楚主角遇到几波对手（拆迁恶人→仇家→宴会层→宗门→裁决宫→前妻清算），作自己写作参考。
- 女频：检查观众是否从头到尾全知、角色信息差是否服务看热闹；前 20/30 集充值点是否重复旧梗。

## 反模式
- 整段复述版权剧情当「知识」；逐集抄剧情而非拆机制。
- 只骂尬不拆机制；或照抄数值与宴会流水线无升级。
- 女频写成战神亲自揍人流水线无关系因果；否定霸总/善良无敌而非拍得更高级。
- 反派用「春药」当终极技反复用（偷听、迷药滥用=创作力匮乏）。
