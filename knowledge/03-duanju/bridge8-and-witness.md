# 八桥段与两性见证放大器
> 来源：查理短剧课 / 3.6
> 权威级别：P0
> 关联 Skills：struct.bridge8, struct.witness_amp
> 关联 Agents：WritingOrchestrator

## 一句话
把五大爽点落成可复用场级桥段：打脸、碾压、运气、地位、集体、因果、极限、哲思；所有模型在「两性见证」加持下威力倍增。

## 为什么讲「模型」
- 好处：① 落地（知道具体怎么写）；② 上手快（拿模型就开写，避免「方法论懂了仍写不出」）；③ 举一反三（模型是骨架，可打出花）。
- 风险承认：确有束缚创作的可能，但可接受。
- 模型合理性旁证：西游记 ≈ 绿野仙踪（催化剂主角 + 缺陷同伴 + 目标 + 结局真相同构），故事路径可复用。

## 八词总览（五爽点 → 八桥段）
| 关键词 | 主要对应爽点源 | 一句话 |
|---|---|---|
| 打脸 | 暴力 + 优势 + 秩序回归 | 我其实很强，你不知还摩擦 → 揭晓 |
| 碾压 | 优势 | 量级碾压（财/智/武等） |
| 运气 | 本质也是优势 | 不劳而获、从天而降 |
| 地位 | 优势/归属 | 万国来朝、众星捧月、一举改他人命运 |
| 集体 | 归属 | 拉踩：我方群体踩对立方 |
| 因果 | 秩序 | 报仇、归位、惩恶扬善 |
| 极限 | 秩序拉满张力 | 最后一刻力挽狂澜 |
| 哲思 | 对秩序的总结 | 真理时刻，替观众把话说明 |

## 八词详解
### 1. 打脸（当前爽剧占比最高、屡试不爽）
模型本质：我其实很牛，我也知道；你不知道（或我不说）→ 你在我面前嘚瑟、摩擦、试探、加码 → 张力拉满 → 打脸。

三种子模型（勿混）：
| 子类型 | 谁主动 | 机制 |
|---|---|---|
| 装逼打脸 | 对方找死 | 我试图表明很牛，他不信、继续装 → 被打 |
| 扮猪吃虎 | 我方主动 | 我低调或故意戏弄 → 再揭穿 |
| 上帝视角 | 幕后大佬 | 旁人吵「传说中那人是谁」，其实就是我 |

举一反三（梅西野球场）：野球小子嘲身高/技术 → 不听解释 → 赌钱 → 赌房 → 赌命 → 必须打脸；打脸方式可加码（隔 50 米进球 → 改隔 100 米）。

### 2. 碾压（来自优势）
三大方向：财力碾压、智力碾压（对方解决不了的我轻松解决）、武力碾压（一出手灰飞烟灭）。延伸：别人朝思暮想的东西我唾手可得；别人朝思暮想的女孩只对我一个人好。

### 3. 运气（爽文逻辑；传统影视不提倡）
- 传统影视守「能量平衡」；短剧可用运气。细化：天降财富/一夜暴富、运气获得武力、运气获得神器（神器认主）、金手指道具、两性好运。
- 变形防腻：不是「我变了」而是「世界变了」（货币通缩，兜里 2000 成世界级富翁）。
- 关键词：不劳而获/从天而降的好东西。

### 4. 地位（从碾压独立，桥段多）
- 经典模型：万国来朝/八方来客（贺寿、剪彩、成立公司 → 各方朝拜、自报家门、带礼物）。
- 加强版：不要只写「别人对你恭敬」，写**主角不经意一举改变别人一生/命运** → 地位悬殊 + 人格魅力。

### 5. 集体（来自归属）
- 最大集体：民族/为国争光；一切「拉踩」向上的群体认同。手撕渣男 = 角色代表女性群体踩渣男。
- 操作关键词：**拉踩**——界定我方群体 vs 对立方，踩对方、扬我方。

### 6. 因果（来自秩序）
报仇雪耻、**归位**（东西本是我家的拿回来、事情扳回轨道）、惩罚恶人伸张正义（报的不一定是私仇）。

### 7. 极限
把情境拉到极限：救人生命最后一刻赶到、炸弹计时最后一秒；收益=主角可绝地反击、力挽狂澜。

### 8. 哲思（真理时刻，慎用过度）
让主角时不时抛哲理结论，成为观众的嘴，替观众说出想说而没说的话。例「人不如狗」：回故里被所有人打压，唯有当年家狗对他好 → 主角结论「人不如狗」。机制=真理时刻；过度则降温，慎用。

## 两性见证：全模型放大器
- 八词里「没有两性」不是没有两性，而是**所有这些模型都必须在两性的见证/加持下**威力才加强。
- 加持方式：打脸现场有两性在场（当众打脸）；打前妻的脸（离婚赘婿文几乎全是打前妻）；面对现任/将在一起的人见证。
- 设计桥段默认动作：八词选模型 + 两性在场 = 默认加强包。

## 可执行清单
- 写单场前先问：这场用八词里的哪一个（或组合）。
- 每集至少命中 1 个桥段关键词；同一词可换子类型（打脸三型）防重复疲劳。
- 大爽点场检查是否有两性见证者；没有能否加。
- 先套模型完成场目标，再个性化变形（举一反三）。

## 反模式
- 只有旁白宣布「他赢了」无场面（爽点没落到动作/画面）。
- 100 集只写打脸一种爽点（见 revise20 法则 2：八落脚要用开）。
- 把运气/哲思用过度（哲思降温、运气滥用会腻）。
- 死背网上「爽点情节表」照抄，而非借原理再创作。
