# 二十节拍大纲
> 来源：查理短剧课 / 3.2；全课程核心精华
> 权威级别：P0
> 关联 Skills：struct.beat20
> 关联 Agents：WritingOrchestrator

## 一句话
把约 150–200 分钟的短剧按「起承转合 = 建立→放大→转折→兑现预期」拆成 20 个节拍；强度可调，节拍与节奏不可丢；大转折（腰）落在物理时长正中。

## 体量与为什么需要结构
- 体量：约 100 集起、每集 1–2 分钟；净内容约 **150–200 分钟**（接近长电影）；字数约 1 分钟 300 字 → 200 分钟 ≈ **6 万字**。
- 没有结构就会一处吵架吵 20 集、无层次无节奏 → **失去节奏 = 失去观众**。
- 产品提醒：短剧依赖用户付费，不能只由着作者审美，要越主流越合乎规律越好；「先拍爽了再说」不适用。

## 四部分叙事（东西方同源）
| 部分 | 预期管理 | 一句话 |
|---|---|---|
| 起 | 建立预期 | 主角想干什么/遇什么事/奇遇 → 观众产生大期待 |
| 承 | 放大预期 | 沿期待线索往前走，放大期待 |
| 转 | 转折变化 | 超出预期，不能直线走 |
| 合 | 兑现预期 | 合回最初期待（如报仇，最终仍要报） |

- 西方对应三幕/四幕；中国对应起承转合。为什么必须分四部分：盯住故事 2 小时且付钱 = 反人性，必须循循善诱（老师表述「多少带点 PUA」）。

## 二十节拍总表
| # | 段 | 节拍 | 核心动作 |
|---|---|---|---|
| 1 | 起 | 环境规则 | 时空 + 世界规则切片，观众心里踏实 |
| 2 | 起 | 主角登场 | 闪亮登场：共情谁、听谁的 |
| 3 | 起 | 激励事件 | 压力/干扰事件（可好可坏） |
| 4 | 起 | 外部目标 | 要解决什么问题 |
| 5 | 起 | 走出舒适区 | 离开稳定态 / 做本不该做的事 |
| 6 | 承 | 初尝红利 | 先爽一把，不能一出舒适区就栽 |
| 7 | 承 | 伙伴/爱情 | 走出后相遇或萌发感情 |
| 8 | 承 | 起始对手 | 有起始目标 → 有起始对手 |
| 9 | 承 | 阻力对抗 | 环境/对手/自身三种阻力 |
| 10 | 承→转 | 故事拐点 | 约一半：虚假胜利或失败，暂告一段落 |
| 11 | 转 | 调整目标 | 原目标不准/无法实现真正愿望 |
| 12 | 转 | 确认对手 | 可换可不换，重新认识对手 |
| 13 | 转 | 冲突升级 | 任务更难，超出预期 |
| 14 | 转 | 第一次决战 | 正面干，往往未准备好也必须干 |
| 15 | 转 | 遭受重挫 | 「灵魂黑夜」；伙伴可死于此 |
| 16 | 合 | 疗伤反省 | 外伤或内伤；想办法 |
| 17 | 合 | 找到解决方案 | 必伴随牺牲/成长（否则早用了） |
| 18 | 合 | 最终决战 | 成功或险胜 |
| 19 | 合 | 胜利后不狂 | 勿屠龙者成恶龙 |
| 20 | 合 | 回到原点 | 带着胜利回最初环境，「归来仍是少年」 |

## 各段要点
### 起（1–5）
- 环境规则：时间 + 空间 + 世界规则切片（人的本能：醒来第一句常是「我在哪」）。
- 激励事件 = 角色在**压力下**产生的**新选择**（按部就班上下班回家 → 理论上「今天没故事」）。可好可坏：中奖/超能力/穿越；离婚/扫地出门/女儿被绑架。
- 走出舒适区多为比喻：公路片是真离乡，否则 = 开始做本不该做的事。

### 承（6–10）
- 初尝红利：走出后先爽（术语「多态化的幸福」= 现实办不了的事，看剧让主角替爽）。
- 三种阻力：
  | 阻力 | 例子 |
  |---|---|
  | 环境 | 自然：雨雷路远水深；人文：查案人人隐瞒 |
  | 对手 | 利益对冲、对着干 |
  | 自身 | 迟疑、胆怯、疏忽、偏执；或「拖后腿」的外部缺陷（女儿被对手盯上） |
- 故事拐点（约第 10 拍 = 一半）：虚假胜利或虚假失败均可，主角甚至以为事已办完。

### 转（11–15）
调整目标 → 确认对手 → 冲突升级 → 第一次决战 → 遭受重挫（灵魂黑夜）。
- 伙伴/爱情若需死亡 → 放重挫位置。
- 第一次正面干 → **必然失败**。

### 合（16–20）
疗伤反省 → 解决方案（牺牲/成长）→ 最终决战胜利 → 不狂 → 回到原点。
- 解决方案必须「早用不了」的那种难度 → 伴随蜕变。

## 腰部（大转折）按类型选用
大转折落在物理时长正中，按故事类型选转法：
| 类型 | 转法 |
|---|---|
| 成长 | 做回自己 |
| 目标 | 换真目标 |
| 困境 | 改应对 |
| 幻想 | 由盈转亏 |
| 谜题 | 改解谜面 |

## 案例：《阿凡达》（20 节拍对照）
| 节拍 | 对应 |
|---|---|
| 环境规则 | 未来地球资源匮乏，需开发外太空 |
| 主角登场 | 杰克：酒吧、轮椅（退伍兵失腿，挫败） |
| 激励事件 | 双胞胎哥哥暴毙；按哥 DNA 造的阿凡达可穿 |
| 外部目标 | 接腿（科研团队有钱有技术） |
| 走出舒适区 | 离开地球去外星 |
| 初尝红利 | 穿上蓝皮有腿、撒欢跑 |
| 伙伴/爱情 | 并肩战友、纳美酋长之女 |
| 起始对手 | 酋长闺女未婚夫（爱情 + 事业对手） |
| 故事拐点 | 情报成功、安排专机回地球接腿——虚假胜利，他没走 |
| 调整目标 | 留下与纳美人并肩 |
| 确认对手 | 从「外星人小伙」→ 地球人 |
| 第一次决战/重挫 | 多人牺牲、身份暴露（曾是卧底）→ 灵魂黑夜 |
| 解决方案+成长 | 驯龙；本体放弃、彻底成为纳美人（牺牲/蜕变） |
| 最终决战 | 战胜入侵地球人 |

> 约 90% 以上电影按此 20 节拍；短剧同样适用。

## 重付费短剧的强度调节
- 节拍与节奏**不能丢**，可调**强度**：不想主角太惨 → 第一次决战「小挫」而非至死，迅速觉醒再找方案。
- 充值关键点设计在后续节奏/预期课（见 `scene-dialogue-hooks.md`）。

## 可执行清单
- 用一句话写下「建立的核心预期」（观众最终要被兑现什么）。
- 按 20 格写出每拍一句话事件（600–800 字大纲级）。
- 检查：起是否建立预期；承是否红利+对手+三种阻力；中点是否拐点；转是否升级+重挫；合是否牺牲成长+回归。
- 重付费：调节惨度/强度，保留节拍顺序；再进单场写作。

## 反模式
- 删掉重挫/疗伤直接开挂终局（缺谷底就没有反差和张力）。
- 有节拍名无内容（每拍只有标签，无具体事件）。
- 流水账对话堆字数，没有「建立→放大→转折→兑现」。
- 第一次决战就赢、直线走到尾（缺转折变化）。

## 与其他课差异（若有）
- 与「十五步」同源升级：短剧用 beat20；通用故事底层用十五步（见 00-meta 或相关通用结构课）。
- 场级细节见 `scene-dialogue-hooks.md`（单场三件事、单场起承转合）；桥段落地见 `bridge8-and-witness.md`。
