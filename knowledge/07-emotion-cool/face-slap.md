# 打脸与对比爽感（装逼打脸三阶设计）
> 来源：九格 / 6–7；狂更猫对比本质
> 权威级别：P0
> 关联 Skills：struct.face_slap
> 关联 Agents：WritingOrchestrator

## 一句话
打脸 = 优势反转的可见对比；装逼 = 真有实力 + 适当炫耀；**信息差是打脸爽感的引擎**——谁知道、谁不知道主角实力，决定爽度。节奏越长、拉扯越足，打脸越爽。

## 装逼四要素
1. **力量**：不限于武力，财富/地位/势力/知识都可，必须是角色最大优势（世界首富的「有钱」就是力量载体）。
2. **适当**：不能随便装，必须有前提理由（本不想装被逼装、忍无可忍）；炫耀学识要补细节/数据/案例，不无限堆砌。
3. **竞争优势**：装的时候拥有压制其他角色的能力。
4. **心理优势**：让读者代入获得优越感 + 让围观者产生羡慕嫉妒（对方心理处下风）。
- 四要素不必全具备，具备一个也 OK；网文语境「装逼」偏褒义（表面装、实际真牛）。

## 打脸定义与四前提
- 打脸**重在「打」与「脸」**（「脸」在「打」之前）：用优于对方的能力直接反击反杀。被打脸的人基本是对手/反派（不一定当时最强，但相对厉害）。
- 装逼打脸四前提：① 谁打（主角）② 打谁（反派）③ 为什么打（展现什么能力/地位）④ 怎么打（直接亲自动手 / 间接别人代劳或反派自作自受）。

## 三阶打脸（情绪强度评分 1/5/10）
### 初阶·主动打脸（1分）
- 三种模式：牛逼主角假装低调主动暴露 / 反派高调主动撩拨主角 / 捧高踩低气氛组到震惊。
- 心理变化：反派「得意忘形→诚惶诚恐→追悔莫及→讨好」；主角「胜券在握→志得意满→嗤之以鼻」；信息差——只有主角和读者知道。
- 六步节奏：告诉读者主角真实实力 + 有装逼计划 → 加强反派塑造 → 主角打脸 → 气氛组震惊 → 反派追悔讨好 → 支持者捧高踩低。

### 中阶·半自动打脸（5分）
- 比初阶多一个**煽风点火的知情者**：配角稍微知道主角实力但不点破；气氛组先踩主角捧反派；知情者刺激反派、鼓吹主角迎战；主角出手碾压；反派 180 度转变、气氛组从捧反派变震惊、知情者幸灾乐祸；结尾气氛组回踩反派、主角嗤之以鼻。

### 高阶·被动打脸（10分）
- 主角不做主动动作，由反派/氛围组/知情人/工具人不停拱火，最后主角受不了显现实力 KO。
- **工具人钩子（关键）**：新增「清楚知道主角真实实力、态度毕恭毕敬」的工具人登场（管家/长期合作者），反派不解「为什么这么有身份的人对主角毕恭毕敬」——给读者下钩子拉伸期待。**工具人必须是有身份地位、名声在外的人**，否则钩子无效。
- 实力分次释放：先露 30% 让反派诚惶诚恐 → 彻底暴露让反派追悔莫及。

### 高级·反派自打脸
- 主角坦荡坦诚暴露实力，反派傲慢不信、继续撩拨，最终自打脸。信息差差异：配角**完全知道且特别崇拜**主角（被动打脸里配角只是稍微知道）。
- 核心规律：套路框架大同小异（告诉读者主角有实力→反派不信/挑衅→反杀），区别在叙事节奏、逻辑次序微调、角色增减（知情者/工具人）。**情绪拉扯越长，积聚力量越大，爽度越高**。

## 可执行清单
- 打脸场检查：抑点（铺垫废柴/低估）、扬点（展示实力）、见证（气氛组/知情者/工具人）、后果（反派讨好/追悔、世界变化）。
- 写每场装逼打脸前先回答四前提；用「信息差表」标注各角色对主角实力的知情程度。

## 反模式
- 无铺垫的突然全胜；打完无后果世界不变；装逼无限堆砌；工具人写成普通打杂（钩子失效）；实力一次全露（无层次）。
