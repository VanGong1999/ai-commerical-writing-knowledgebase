# 漫剧进阶：核心梗四步法、四幕结构与题材红线

## 一句话
创新不是凭空创造，是**老核心梗重新组合**；用「世界观→身份反差→限制型金手指→核心动作」四步法造梗，用 100 集四幕模板防跑偏，选题前先过题材红线。

## 2026 漫剧两大趋势
- **男频求变**：早期题材（末世/重生/系统/玄幻）仍可写但观众已看多，创新题材更易出头；从无脑逆袭升级为**高智破局**（高智、杀伐果断人设，如《仙逆》王林、《剑来》陈平安；男频男主必须理智，优柔寡断是致命的）。
- **女频崛起**：处于爆发期，**比较容易过稿**；底层原因是 AI 仿真人技术提升（早期女频没爆因女性观众对画面情绪要求更高，早期漫剧表情僵硬达不到；现在男女主做得好看、情绪细腻）。女频核心是**强情绪、大女主独立人格**（女主独立完成核心事件，男主做工具人辅助；复仇层层递进不一步到位）。
- 跟热点策略：热点剧出来立马跟写、立马投**过稿快**的公司（磨稿慢的公司会让你错过热点）；更优是**预测热点**走在观众前面。

## 漫剧表现形式与赛道匹配
| 形式 | 特点 | 适合题材 |
|---|---|---|
| AI 仿真人剧 | 2 月百强占比近 60%；画面近真人、服化道细腻；可快速生成虚拟演员、低成本大场面 | 宅斗/逆袭/甜宠等人物冲突情感为主、打斗少；强情绪女频 |
| 2D/3D 漫剧 | 卷精品；榜单前两名仍是 2D；视觉表现力男频玄幻不可替代 | 玄幻修仙/规则怪谈/科幻；表情夸张 Q 版偏 2D、打斗多偏 3D |
| IP 改编 | 番茄/阅文海量 IP 放出（数千至近万本） | 自带流量 IP；需提炼精彩剧情、改造慢热开头 |
| 沙雕漫 | 适合沙雕搞笑/脑洞反转 | 不推荐长期投入（未来成本或被 AI 漫剧取代） |
- 写过短剧剧本者优先投 AI 仿真人漫剧；投稿前先看制作公司擅长方向。
- 「三人团队五天做一部剧」是营销号吹嘘；精品需团队反复打磨。

## 核心梗四步组合法
1. **选世界观**：直接「抄作业」——男频：末世/仙侠/克苏鲁/无限流/规则怪谈/国运竞技；女频：古代宅斗/娱乐圈/豪门/穿书/重生/兽世。小众创新赛道（名著同人/第四天灾/赛博朋克）竞争小。**不建议西幻**等非主流（脱离热点、受众缩小约 30%）。
2. **叠加人物身份（反差感优先）**：公式「**本来应该是 A 的人，实际上是 B**」；反差要有**话语权落差**（小杂役实际是山头大佬，大佬必须设定世界里真有话语权）。
3. **加金手指（带限制）**：避免一刀 999；2026 观众爱看**有限制、需智斗、会坑主的金手指**（预判但只预判坏事/读心只听到吐槽/系统有 KPI/重生只看完小说但只记得关键剧情）；**组合技**思路（看似废柴的金手指组合起来无敌）。
4. **设计核心动作/追剧点**（= 期待感）：每集解决小目标、全剧主线解决大目标（逆袭/复仇/拯救/攻略）；**三集一小爽、十集一中爽、二十集大爽（大爽放付费卡点后）**；全剧目标一旦确定，所有剧情围绕它写，别跑偏到支线。

## 元素叠加示例（精选）
- 男频：规则怪谈+多子多福（养成系统）；国运竞技+三角洲热点词引流；国民 IP（西游）+颠覆性脑洞（《错把玉帝当亲爹》35 小时破亿）；克苏鲁世界靠预判怪物规则苟活+乌鸦嘴。
- 女频：真假千金联手推翻权贵（双女主）；宫斗读心术躺平；女扮男装考状元掉马；重生复仇+母亲联手掀翻家族牌位；乙游系统多男主（《大小姐你把恶魔执事调成啥了》）；娱乐圈万人嫌摊牌（爸首富妈影后干爹国家队）。
- 通用：克苏鲁+治愈+反向恐怖（萌萌小章鱼是旧日支配者）；天道+KPI；NPC 觉醒改代码；扫把星+锦鲤 KPI 系统。

## 100 集四幕通用结构模板
- **第一幕（1–25 集）**：立人设世界观 + 首次逆袭 + 种下最大悬念。1–3 集虐主角+金手指觉醒+首次打脸（第 3 集一定要打脸）；11–12 集被准 boss 压制；23 集命悬一线；24 集绝地反杀；25 集庆祝+闪回+预示新危机。
- **第二幕（26–50 集）**：扩地盘 + 收核心伙伴 + 首个大 boss（全面升级）。
- **第三幕（51–75 集）**：危机低谷 + 绝地反击（误解/孤立/躲绝地/获得新传承/清算背叛者/惨胜）。
- **第四幕（76–100 集）**：终极决战 + 填坑 + 留钩子（预留 3–5 集收尾；或开放性结局；要拍第二季结尾留钩子）。
- 底层逻辑：每集要有任务并检查是否推动主线；打 boss 必给收获；每幕结尾预示新危机。适合**手写/手搓**剧本（AI 直接按模板写可能不出彩，AI 用来生成框架，最终自己优化）。

## 开场类型库 + 结尾钩子
- 开场：虐点开场（越狗血越惨越好，女主直接被活埋）、危机开场、系统开场、重生开场、掉马开场、规则开场、搞笑开场、甜宠开场（「直接擦边」）、高能开场（爆炸/打斗/超能力对决）。
- 结尾钩子：用一句台词预示冲突/秘密；让主角立 flag；宣布震惊事件；定格在震惊情绪上（「等一下」+众人惊讶表情直接卡掉）；反转/新想法/未回答的问题/神秘对白/预言/转折点。

## 桥段练习方向
- **权谋——多用信息差**：公开做 A 误导、暗中布 B、敌人基于 A 决策中计再收割（白天运沙袋装粮足、夜里烧水装炊烟诱敌夜袭反埋伏；朋友圈发在医院排队、实际在敌对公司楼下截胡客户）。
- **甜宠**：结合暧昧 + 搞笑，设计名场面（男主是首富却冒充男宠，女主扇前男友巴掌时他茶里茶气「你干嘛奖励他」）。
- **爽文/催泪/搞笑/悬疑反转/恐怖**：分类收集素材、分类练习；恐怖题材练「**不用鬼、用反常的熟悉感制造恐怖**」。
- 每集至少设计一个**名场面桥段**。

## 题材红线与审核风险（写作禁忌）
| 风险项 | 说明 |
|---|---|
| 出马仙 | **尽量不要写**；与出马仙相关的剧**全部被下架**；写鬼不要写真鬼 |
| 血腥暴力恐怖画面 | 不易过审；抖音/红果对恐怖题材严格筛选 |
| 国民 IP/名著（西游/封神/三国/红楼） | 自带认知度降低传播门槛，但**不要魔改原剧情**；可用原著角色写**原创剧情**，角色形象必须正面 |
| 金庸/迪士尼等 | 会侵权；可用角色但不碰、不魔改原剧情 |
| 《凡人修仙传》类 | 官方允许二创但**不允许用 AI 直接创造续集并产生收益**（有用户被起诉案例） |
| 花木兰等地域文化英雄 | 不魔改、不碰，否则后果严重 |
| 神话/童话（牛郎织女、黑童话、反套路神话） | 可以写 |
| 历史人物（霍去病/嬴政/花木兰） | 可以写 |
- 选题阶段先用红线清单过滤核心梗，避免写完才发现不能拍。

## 可执行清单
- 选赛道（男/女频）→ 选形式（仿真人/2D/3D/IP）→ 四步法生成 5–10 个核心梗 → 选定+设计反差角色 → 定主线+写详细提纲 → 写正文（开场+钩子+名场面）→ 逐集检查 → 投稿过稿快的公司。
- 金手指必加限制（时效/次数/KPI/坑主）；世界观从主流清单选；先定追剧点再写提纲。

## 反模式
- 世界观选西幻等小众；金手指一刀 999；不写提纲写到十几集主角忘了复仇；核心梗理念不贯彻（躺平文写一半去搞事业）；女频女主依赖男人；复仇一步到位；甜宠干巴；开场平淡结尾无钩子；写红线题材；魔改国民 IP/碰地域文化英雄。
