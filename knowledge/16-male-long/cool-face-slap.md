# 男频爽点密度与装逼打脸
> 来源：狂更猫 / 12、22、25、61；九格 / 6–7；零基础 / 35–36、49；07-emotion-cool/*
> 权威级别：P0
> 关联 Skills：male_long/cool-density, structure/face-slap-tiers
> 关联 Agents：WritingOrchestrator / MaleCoolDensityAgent

## 一句话
男频爽感 = 优势反转的可见对比 + 信息差期待兑现；章级要有密度曲线（一章 ≥2～3 个引爆点），打脸要有抑扬、见证与后果。

## 打脸链路与四要素
- 打脸链路：铺垫蔑视/低估 → 展示实力 → 反应扩散 → 收获盘点；对比越强爽感越强。
- 装逼四要素：力量｜适当出手理由｜竞争优势｜心理优势（读者优越感 + 围观情绪）。
- 打脸四前提：打脸主角｜挨打反派｜目的｜方式（直接/间接）。
- 三阶：主动打脸（爽直接）｜半自动（铺线情势帮打）｜被动（反派自曝，信息差最大）。

## 期待感与信息差
- 信息差期待：未发生时往往更爽；金手指压缩过程，但读者预知要到位。
- 欲左先右：先定碾压/结算画面，再写轻视铺垫。
- 期待被弱化 → **读者预知升级**（补更强对手/新地图/强化目标，勿重复硬打）。

## 章级密度（零基础 35 + 狂更猫 12/61）
- 一章至少 **2～3 个**可感引爆点；小爽维持追读，大爽抬阶段；连续同震惊层无新内容 = 水。
- 爽点按需求层次选型（力量征服 / 成长逆袭 / 智谋 / 机遇等）；男频偏力量与智谋。
- 反派心理常见弧：得意忘形 → 诚惶诚恐 → 追悔莫及 → 讨好；主角侧胜券在握感与读者同步。
- 男频女性正反馈（零基础 49）：男主赢了须得崇拜等正向反馈（目光炽热/结巴问实力），「赢了还被女生嘲」= 大堵点；女性倒贴可作爽点机制但须服务目标与信息差。

密度扫描：标每章蓄压/小爽/大爽/缓冲；标真空（多章无小爽）与堆砌（连爽无缓冲）。

## 反模式
- 无铺垫突然全胜；打完世界不变。
- 爽点 = 给好处（缺对比）；藏信息当悬念（新人易翻车）。
- 预知不足还强压主 → 只剩恶心；重复震惊流水线无升级曝光。
- 全程高喊无起伏，或纯过渡章零情绪。
