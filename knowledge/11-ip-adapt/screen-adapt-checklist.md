# 影视向改编检查单
> 来源：红娘子写作课程（第11课）；0基础小说写作课（第11课，同源）；编剧孵化营硬性要求
> 权威级别：P1
> 关联 Skills：ip.adapt, qc.redline
> 关联 Agents：WritingOrchestrator

## 一句话
影视向不看「文笔」，看「可拍性」：大背景值钱、人物立得住、冲突密集新鲜、行为有逻辑、主题能升华，且**过得了审查**是前提；框架完整即可先卖故事，禁大段闪回/旁白依赖。

## 影视向检查清单（红娘子第11课）
- [ ] 有可拍的**完整故事框架**（不是百万字注水）
- [ ] **大背景**值钱、可落地
- [ ] 人物立得住
- [ ] 冲突密集且新鲜
- [ ] 行为有逻辑
- [ ] 主题能升华
- [ ] **过得了审查**

## 关键要点展开
### 大背景最值钱
- 卖版权时，可拍、可落地的「大背景/设定」比单个情节更值钱（案例：《流浪地球》的大背景）。
- 「框架完整即可先卖故事」：不必等写到百万字，框架成立就能谈。

### 视觉 + 动作 + 蒙太奇（影视三件套）
- 影视是视听语言，落笔写「能拍出来的」：动作、视觉画面、蒙太奇节奏，而非大段心理描写/意识流。
- 禁闪回、旁白依赖（课内口径）——靠画面和动作推进，不靠解说。

### 行为逻辑（红线）
- 角色行为必须符合逻辑，否则观众出戏（案例：龙妈第八季被骂 = 行为逻辑崩坏）。
- 与写作课程2「性格决定命运」、0基础「每个举动可解释」同向。

### 政策审查是前提
- 过不了审 = 不可拍 = 白写；动笔前先确认红线（详见 09-quality/jiuge-redline-policy）。
- 政策会变，品类边界对照当下。

## 与传统网文的差异
| 维度 | 网文长篇 | 影视向 |
|---|---|---|
| 目标 | 追更、付费 | 卖版权/可拍 |
| 体量 | 越长越养读者 | 框架完整即可 |
| 表达 | 可大段心理/旁白 | 视觉动作蒙太奇 |
| 硬门槛 | 无大纲必崩 | 过审 + 可拍 |

## 可执行清单
- [ ] 逐条过影视向七项清单（框架/大背景/人物/冲突/逻辑/主题/过审）。
- [ ] 自查「视觉+动作+蒙太奇」是否到位，删大段心理描写/旁白/闪回。
- [ ] 行为逻辑红线：每个关键决策能解释（性格决定命运）。
- [ ] 过审点前置确认，避免写完才撞政策。
- [ ] 框架成立即谈版权，不必等完稿。

## 反模式
- 不可拍的大段意识流/心理独白。
- 依赖闪回、旁白解说推动剧情。
- 行为 OOC 无动机（龙妈式崩坏）。
- 忽略审查，写到一半发现过不了审。
- 只堆文笔不讲可拍性。

## 与其他课差异
- 本文是「改编/影视向」的可拍性检查；若要从零构建一小时电视剧试播集的结构（四原型/四幕/八角色），见同目录 xiezuo1-pilot-structure。
- 与九格「IP 改编/漫剧短剧」不同：本文是传统影视向，九格偏漫剧/短剧载体（详见 jiuge-ip-adapt、novel-to-manju）。
- 红娘子/0基础同源口径一致；「禁闪回旁白」为课内口径，具体以当期审查政策为准。
