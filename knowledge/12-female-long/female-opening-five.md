# 女频开篇五要素与前三章
> 来源：狂更猫 / 09、40、45；零基础开篇设定（28–29）
> 权威级别：P0
> 关联 Skills：female.*, hook.*
> 关联 Agents：CoreHookAgent

## 一句话
第一章五要素：女主是谁/在怎样的世界、金手指、面临现状、思考行动、有效突发；前三章按对标「章功能」仿、不仿事件。

## 第一章五要素（09/40/45）
1. 女主是谁、在怎样的世界。
2. 金手指。
3. 面临现状（出场人物宜少）。
4. 对现状的思考/行动（主线方向）。
5. **有效突发事件**（能接第二章，非空钩子「门外有声音」）。

## 前三章骨架（45）
```text
定保留主线 → 四换三 → 拆对标前三章「章功能」
→ 按相同功能写自己情节 → 第一章五要素 + 钩子
→ 信息靠对话心理渗透，忌说明书
→ 仍不会则退回 1+5 缝合法
```
- 第二章兑人设；第三章按渣男/配角分叉。
- 有感情线：尽量前三章出男主（36）。

## 女频开书全流程（40）
```text
定题材 → 1对标+5参考（看60拆20）→ 四换三或缝合
→ 题目简介 → 五要素第一章 → 第二章兑人设 → 第三章按渣男/配角分叉
→ 卡文只找同设定下的反应
```

## 与男频开篇对照
| 维度 | 男频（46 五信息点） | 女频（09 五要素） |
|------|---------------------|-------------------|
| 首章 | 世界背景/穿越重生/危机/系统+思考定目标/进入事件 | 谁/世界/金手指/现状/思考行动/有效突发 |
| 基调 | 展示主角优势（前五章） | 立人设 + 情绪 + 主线方向 |
| 信息 | 一次给清、境界简单立刻解释 | 靠对话心理渗透，忌说明书 |

## 可执行清单
- 第一章勾五要素；突发是否「有效」（能接第二章）？
- 感情线男主是否前三章出现？
- 信息是否靠对话/心理渗透而非说明书？

## 反模式
- 第一章人物过多；空钩子「门外有声音」。
- 信息后置（第一章剧情完、第二章才补设定）。
- 新人硬写纯日常甜宠/校园氛围开局。

## 与其他课差异（若有）
- 权威：女频开篇以**狂更猫**五要素 + 前三章章功能为准；**零基础**的「设定开篇（人物魅力/热点元素）」与五要素的「谁/世界/金手指」相通，可作背景补充，但零基础无「有效突发」这一女频专属钩子。
- 通用开篇三法见 `04-webnovel/opening-attract.md`。
