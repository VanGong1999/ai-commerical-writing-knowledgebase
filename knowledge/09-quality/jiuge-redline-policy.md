# 写作红线、平台政策与雷区规避
> 来源：九格 / 15.md（政策与平台红线 + 创作核心雷区）、14.md（选题雷区）
> 权威级别：P0
> 关联 Skills：quality.policy, topic.redline, quality.logic
> 关联 Agents：PolicyCheckAgent

## 一句话
政策红线（政治/色情/暴力/价值观/未成年）绝对不能碰；平台红线（抄袭洗稿/标题党/违规导流/断更烂尾/敏感词）会限流甚至封号；创作雷区（人设崩塌/反派降智/同质化/恋爱脑雌竞）是隐形扑街原因。

## 政策红线（全国通用，绝对禁止）
| 类别 | 内容 |
|---|---|
| 政治敏感类 | 国家领导人、政治事件、敏感历史、分裂言论、宗教极端思想 |
| 低俗色情类 | 露骨亲密描写、低俗色情对话、性暗示、未成年人色情；女性言情可写情感互动但须干净得体 |
| 暴力血腥类 | 过度暴力、血腥场景、自残自杀引导；校园/家庭暴力过度渲染；可写冲突但须传递正向价值观 |
| 价值观扭曲类 | 美化出轨/小三/家暴/犯罪；传拜金/享乐/躺平负面价值观；过度渲染不婚不育（与国家政策相违背）；女主可逆袭搞事业但须守正向价值观 |
| 未成年人不良引导 | 引导早恋、辍学、攀比、打架斗殴；有未成年角色须正向引导 |

## 平台专属红线
| 类别 | 内容 |
|---|---|
| 抄袭、洗稿 | 直接抄袭或洗稿搬运他人剧情人设，绝对禁止；坚持原创、避免借鉴过度 |
| 标题党、封面党 | 标题与内容严重不符、封面低俗夸张会限流（番茄等正在整治） |
| 违规导流 | 插入微信/QQ/二维码等导流信息，绝对禁止，可能直接发不上去 |
| 恶意断更烂尾 | 频繁断更、无故断更、仓促烂尾，影响推荐口碑甚至被处罚 |
| 敏感词汇 | 各平台有敏感词库，低俗/政治敏感词会限流屏蔽；**敏感词库实时更新**，需随时关注时事政策 |
- **亲历案例**：科技爱国文写「某某某首长」一直能过审，某天突然违规无法上架，排查发现政策变化「首长」成敏感词；改成相似但不敏感表述后顺利上架。**写作不能脱离社会现实，要随时保持对时事政治的敏感度。**

## 创作核心雷区（隐形雷区）
### 人设类（最易崩塌、影响读者粘性）
- **人设崩塌**：前期设定与后期行为矛盾且无铺垫（清醒搞事业女主后期为男主放弃事业）。避坑：创作前梳理核心特质和成长弧光；改人设必须有明确剧情支撑。
- **工具人配角**：配角无性格成长线、全程只为主角服务。避坑：给配角简单性格和成长线。
- **反派降智**：为烘托主角强行让反派智商下线、放水。避坑：反派要有自己目标和逻辑、智商在线；女主靠自身能力取胜。「不要把读者当傻子，把读者当傻子可能你就是最大的傻子。」

### 剧情类（影响追读率）
| 雷区 | 避坑 |
|---|---|
| 剧情悬浮、逻辑混乱（实习生一夜变高管） | 剧情贴合现实和题材逻辑，转折有合理铺垫 |
| 套路化严重、同质化 | 热门套路上加差异化亮点（重生年代文不搞种田搞特色手工业） |
| 无爽点真空、爽点拖沓 | 每 8~12 章一个小爽点、40~60 章一个大爽点，爽点干脆不拖沓 |
| 强行虐心、刻意狗血（一句话能解释却故意不解释） | 虐心合理有铺垫，虐后及时给治愈爽点 |

### 价值观类（影响口碑、降低改编潜力）
- **女主恋爱脑、放弃自我**：爱情是锦上添花不是全部，保持独立、有事业梦想底线。
- **美化攀比拜金**：搞事业财富是成长收获而非核心目标，传递努力奋斗。
- **雌竞（女性祸害）**：女主与其他女性全程对立陷害，无女性互助（已不流行）；加入女性互助情节（闺蜜扶持、帮助困境女性）。

## 选题雷区（必须记住）
| 雷区 | 表现 |
|---|---|
| 题材冷门 | 读者基数小，写得再好也难获市场回报 |
| 同质化严重 | 无差异化（女主被全网黑逆袭/总裁+小白花/嫡女复仇手撕庶妹） |
| 选题太大 | 「女主统一天下/拯救世界」→ 剧情空洞逻辑混乱 |
| 选题太小 | 只写男女日常恋爱无核心冲突成长线 → 写几十万字只能烂尾 |
| 选题与能力不匹配 | 不了解职场写职场、不了解古代写权谋 → 细节失真 |
| 强行加入热门元素 | 为跟风穿书而穿书，穿书后与剧情无关 |

## 可执行清单
- 选题阶段先过红线清单（政策红线 + 平台红线 + 选题雷区），避免写完才发现不能发。
- 敏感词随时自查（关注时事政策变化）；不插导流信息、不做标题党封面党。
- 人设/剧情/价值观三类雷区逐项排查；反派智商在线、女主独立、配角有成长线。

## 反模式
- 涉及政治/色情/暴力/价值观扭曲/未成年不良引导；抄袭洗稿、违规导流、断更烂尾。
- 反派降智、人设崩塌、工具人配角、同质化、无爽点、强行虐心、恋爱脑、雌竞。
