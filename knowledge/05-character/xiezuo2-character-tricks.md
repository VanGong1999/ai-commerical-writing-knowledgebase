# 人设五技巧与行为逻辑（写作课程2）
> 来源：写作课程2（讲师小璇，第6/7/8/9/10课）
> 权威级别：P1
> 关联 Skills：char.bible_big5, char.empathy
> 关联 Agents：CharacterBibleAgent

## 一句话
人设靠「属性、矛盾反差、小处标签、所见所想精神、缺陷」五技巧立起来，靠「性格决定命运」这条红线守逻辑；金手指要有限制，代入感靠六觉等五法，感情线九字真言「爱不得、恨别离、意难平」。

## 人设五技巧（第7课）
| 技巧 | 说明 |
|---|---|
| 角色属性 | 身份、定位、能力基本面 |
| 矛盾反差 | 外表与内在/身份与行为的反差制造记忆点 |
| 标签化（着眼小处） | 用一个小动作/小癖好当标签，不空喊 |
| 内在精神（所见+所想） | 写角色看见什么、心里想什么，暴露精神世界 |
| 缺陷描写 | 有缺陷才立得住，完美=假 |

## 人设三盲区（第7课，红线）
1. **角色要区分**：不同角色不能一个模子、说一样的话。
2. **同人特点要重复聚焦**：写同人/群像时，抓每个角色的核心特点反复强化，不散。
3. **行为要符合逻辑（性格决定命运）**：一切选择从性格出发，可解释。

## 金手指：7类 + 7特质（第8课）
- **7类形态**：人物 / 物品 / 系统 / 血脉天赋 / 主角光环 / 信息差 / 精神。
- **7特质（重点）**：唯一性、升级空间、有限制、隐匿、易懂、不要太多、不完全依赖。
- 金句：**主角不是天下无敌，只是在一定范围内比较强。**

## 代入感五方法（第9课）
| 方法 | 说明 |
|---|---|
| 六觉法 | 视听嗅味触 + 心理，全面调动感官 |
| 后果法 | 写行动的后果，让读者替角色捏把汗 |
| 聚焦法 | 聚焦单一焦点，不散焦 |
| 重复法 | 关键意象/动作重复强化 |
| 普纵法 | 普遍困境 + 纵深挖掘，引发共鸣 |

- 先决条件：**先引起读者兴趣**，代入才有落点。

## 感情线（第10课）
- 定义：主配角心理活动与行为选择体现的精神世界大集合。
- 递进三方向：**伦理 → 心理 → 生理**。
- **九字真言：爱不得、恨别离、意难平。**
- 别写「没嘴人」（有事不说憋着的角色）；**有糖有刀才是高级**。

## 爽点三板斧 + 七种爽感（第6课，底层能力）
- **三板斧**：环境（含因果逻辑）、感官（含心理博弈）、落差对比（打脸后的变化）。
- **七种爽感**：成就 / 压抑后的宣泄 / 满足三观 / 解决超经验麻烦 / 信息差 / 毁灭厌恶的小人 / 上位者的凝视（如三体）。
- 爽点本质 = 对人欲望的解剖；不知道写什么爽，就问「我为什么震撼/头皮发麻/喊爽」。

## 行为逻辑红线（贯穿人物层，交叉印证）
> 性格决定命运（人设）= 金手指有限制 = 不写没嘴人（感情线）= 占领道德制高点（高潮）——都在强调**行为要符合逻辑、情理**。

## 可执行清单
- [ ] 人设卡补全：反差点、小标签、缺陷、行为禁区、所见所想。
- [ ] 每个角色过「三盲区」：区分度？特点聚焦？行为可解释？
- [ ] 金手指过七特质，重点「有限制、不完全依赖」。
- [ ] 代入感用六觉/后果/聚焦/重复/普纵五法自测。
- [ ] 感情线检查：递进三方向 + 九字真言 + 有无「没嘴人」。
- [ ] 与 soul-check（灵魂拷问）、empathy-three（共情三招）联用。

## 反模式
- 行为 OOC 无补动机（违反性格决定命运）。
- 金手指无限制、一开局天下无敌。
- 角色同质化、说不清「这个角色和那个角色有何不同」。
- 「没嘴人」憋着不说，靠误会推进（廉价）。
- 人物完美无缺陷。

## 与其他课差异
- 与九格「人物深度/灵魂拷问/共情三招」互补：本课偏「技巧清单 + 行为逻辑红线」，九格偏「深度塑造/成长弧」。
- 与 0基础实战课「废人物不写、用行动说话、命运不得不、人物三度空间」同向，可互相印证（见 13-short-fiction/zero-practice-short-long）。
- 爽点三板斧/七种爽感属写作课程2 底层能力（第6课），服务于情节与高潮，与结构篇联用。
