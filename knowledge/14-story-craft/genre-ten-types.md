# 类型片十大共情点
> 来源：编剧孵化营（13–15 类型片 1–3）
> 权威级别：P1
> 关联 Skills：topic.*
> 关联 Agents：MarketBriefAgent

## 一句话
按「**主共情点**」给故事归类（施奈德《救猫咪》十类型）：金羊毛 / 伙伴之情 / 超级英雄 / 鬼屋 / 侦探 / 如愿以偿 / 麻烦家伙 / 变迁仪式 / 愚者成功 / 被制度化；一个故事可有多个共情点。

## 底层认知：分类是简化思维
- 类型片＝分类，是**简化思维**（人类高级认知、节省脑能耗）；两大局限：**不可能绝对精准**、**一刀切必有过渡层/灰色地带**。
- 学习用分类、创作看个体——面对自己唯一的故事时，别被类型绑架。
- 施奈德十类型从**创作者侧**出发、以**观众共情点**分类，契合「从创作者角度找创意」的思路。

## 十类型速查（主共情点 / 核心要素 / 案例）
| 类型 | 主共情点 | 关键要素 | 代表案例 |
|---|---|---|---|
| 金羊毛 | 收益（目标） | 路径＋团队＋目标（团队＝一个人的拆解） | 西游记、绿野仙踪、心花怒放、泰囧、盗墓类 |
| 伙伴之情 | 人物关系 | 互补＋沟壑；四阶段 | 绿皮书、触不可及、杀人回忆、泰坦尼克号 |
| 超级英雄 | 有能力的人拯救世界 | 能力/命门/对手/使命 | 漫威、哪吒、西游记 |
| 鬼屋 | 受惊吓（对神秘力量的恐惧） | 密闭空间＋神秘力量（不可沟通）＋原罪＋群像 | 海神号、大白鲨、侏罗纪公园、招魂 |
| 侦探 | 解密（逻辑满足） | 秘密＋探秘者＋探秘者自我牺牲（融入案情） | 福尔摩斯、利刃出鞘、神探夏洛克 |
| 如愿以偿 | 那个「愿」 | 愿望＋咒语＋教训（金手指终点前帮助、终点后阻碍） | 夏洛特烦恼、你好李焕英、重返17岁 |
| 麻烦家伙 | 无辜 | 无辜＋麻烦＋生死（不能做原罪） | 鬼子来了、疯狂的外星人、波斯语课 |
| 变迁仪式 | 人人会经历的人生变迁 | 人生变迁＋过激/回避处理＋改变自己 | 塔利、内布拉斯加、驾驶我的车 |
| 愚者成功 | 戏谑的成功 | 愚者＋伟业＋成功（喜剧但勿荒诞） | 阿甘正传、功夫熊猫、律政俏佳人 |
| 被制度化 | 对抗体制 | 环境制度＋人群＋主角（新来的/边缘人/觉醒者）＋牺牲 | 飞越疯人院、失控玩家、疯狂原始人 |

## 前四型（古老四类型，有神话渊源）
### 金羊毛
- 一个主角＋几个小伙伴踏上寻找宝物的征程，虽常拿不到「宝物」却找到更重要的东西。**涵盖最广**（大部分公路片、抢银行/骗子/盗墓类）。
- 三支点：**路径**（目标悬在最后，路必须铺明确、阶段性给甜头）、**团队**（场景常换、配角带不走，需团队才有交流）、**目标**（共情点悬在最后）。
- 核心心法：**团队本质是一个人被故意拆解出来的**（西游记师徒＝贪嗔痴拆解）；团队不拆、一人上路时，主角＝**催化剂人物**（每站 NPC 必有一方成长）。

### 伙伴之情
- 两个主体「相爱」的故事，兄弟情与爱情写法一模一样。两要素：**互补**＋**沟壑**。
- 爱情成就四阶段：**互助 → 共谋（一起干件坏事）→ 误会/背叛 → 成长为对方**。
- 撕裂诀窍：**选择权不平衡**（一方只有一条路，另一方有别的选择；第三者是最简单实现）。
- 案例拆点：绿皮书「换座位戏」完成身份交叉；杀人回忆「讲究证据者崩溃、莽夫反而讲证据」的完美交叉。

### 超级英雄
- 四要素必背：**能力 / 命门 / 对手 / 使命**（使命要大、拯救世界）。渊源＝对神的崇拜（坎贝尔《千面英雄》：千面英雄只有一面）。
- 神话改编铁律：**必须有群众基础**（西游体系 > 封神榜体系）；从《山海经》扒冷门神怪＝对观众没有意义。
- 大趋势下行（我们越来越不信神；个人英雄主义是西方文化），可「现代化落地」（厉害的特工/警察/父亲＋四要素）。

### 鬼屋
- 有限（密闭）空间内神秘力量追捕残杀。不限于「鬼」（海神号、大白鲨、侏罗纪）。
- 要素：**密闭空间＋神秘力量＋原罪**（主角有罪，恐怖才成立）＋**群像**（社会比喻＋要死人，让人看不出谁是主角）。
- 神秘力量核心要求：**不可沟通、不可预测**（刘慈欣「不可沟通是最大的恐怖」）。金刚可沟通→伙伴之情，不是鬼屋。
- 怪兽规律：大＋基于现实才吓人，数据最好的是「蛇」（课程口径）。恐怖片有稳定票房天花板（约 2 亿，课程口径），小众。

## 后六型
### 侦探（解密类）
- 抛谜题，激发观众解密欲望。**有门槛、小众**（不是大众需求，但逻辑满足是真实刚需）。三要素：秘密＋探秘者＋探秘者自我牺牲。
- 铁律：**探秘者信息与观众高度对称**（玩信息差＝戏耍观众）；探秘者「融入案情」是不得已的结构性方法（律政片打到最后打自己的案子）。

### 如愿以偿（金手指类）
- 主角如愿得到极想要的东西，最后回归现实发现最珍贵的是什么。三要素＋诀窍：**愿望 / 咒语 / 教训**；**金手指终点前是帮助、终点后是阻碍**；第四幕**扔掉金手指**解决最大危机。

### 麻烦家伙
- 普通人（无辜者）卷入大麻烦且危及生命。**主共情点是「无辜」**；**不能给主角做原罪**（否则观众觉得活该）；用平凡方法解决（平凡但不平庸）。

### 变迁仪式
- 人人都会经历的人生变迁（青春期/失业/离婚/失恋/绝症/亲人离世/产后抑郁/老年痴呆），主角做出过激/回避处理，最后**改变自己**。**最容易写高逼格、最易得奖**。
- 辨析：公路片不等于金羊毛——判断标准永远是「共情的是什么」（《内布拉斯加》共情「我爸老糊涂怎么办」，是变迁仪式）。

### 愚者成功
- 愚者＋伟业＋成功＝戏谑成功，用「低于观众的主角＋高于观众的伟业＋竟成功」制造落差爽感。往往做成喜剧，**先喜后感人，但别流于荒诞**。

### 被制度化
- 体制内人人做同一选择，主角偏要对抗。支点：环境制度（须现实有根据或现实夸张）＋人群＋主角＋牺牲。主角三种：新来的/边缘人/觉醒者。

## 多共情点叠加
一个故事可有多个共情点：**泰坦尼克号＝伙伴之情＋鬼屋；杀人回忆＝侦探＋伙伴之情；触不可及＝伙伴之情＋变迁仪式**。判断标准永远是「共情的是什么」，不是「有没有上路/有没有怪兽」。

## 可执行清单
1. 拿 1500 字梗概，判断符合哪一（或两）种类型，提炼该类型关键要素；缺失即补。
2. 选题时写「主共情点＋辅共情点」，不超过两种。
3. 写小众类型（鬼屋/侦探）主动叠加一级需求元素（血腥/悬疑暴力暗示，中性理解）。
4. 神话改编先查「群众基础」，没基础的冷门神怪不如不写。

## 反模式
- 类型元素乱炖、无主共情点；纠结于「哪个类型」而忘了作品本身。
- 照搬西方类型（写「中国西部片」，应写「闯关东」）；个人英雄主义硬套东方语境。
- 鬼屋给神秘力量「可沟通」；麻烦家伙给主角做原罪；愚者成功流于荒诞。

## 与其他课差异
- 类型片（孵化营）按「主共情点」分类，与 CTFDP/十大设定（选材工具）互补：CTFDP 是「从哪个角度找创意」，十类型是「归入哪个共情赛道」。
- 权威级别 P1（课程分类法，非底层通用骨架）；与 `topic.*`、`MarketBriefAgent` 关联用于选题与市场定位。
