# 故事建立信任与公共叙事三段论
> 来源：馒头商学院·哈佛故事课 / 全课程核心精华 + 全课程知识体系（讲师郭博文，源于 Marshall Ganz 公共叙事框架）
> 权威级别：P0
> 关联 Skills：—
> 关联 Agents：WritingOrchestrator

## 一句话
故事的本质是建立信任（催产素）；用三段论（我的故事 + 我们的故事 + 眼下的故事）和英雄之路组织故事，用情绪推动行动。

## 故事的本质：信任（催产素）
- 故事 = 人类赋予世界**意义**、建立**信任**的方式。
- 生物学基础：听故事分泌**催产素（Oxytocin）**——放松、信任、平稳。
- 会讲故事 = 唤起情感 = 建立信任 = 影响行为（运营 / 营销 / 产品 / 文案的底层能力）。
- 当代三大社会问题（信息过载、数据逻辑依赖、社交机会暴增但信任缺失）→ 讲故事能力更稀缺。
- 故事六大好处：吸引注意、帮助理解、画面记忆、唤起情感、建立信任、提供谈资。

## 情绪决定行动论
```
价值观 ──（缺：情绪）──→ 行动
```
- 「道理我都懂但改不了」= 只听了道理，没感受到情感。
- 故事的作用：创造情感 → 唤醒价值观 → 推动行动（转发、点赞、购买、追随）。

### 情绪两张清单
| 积极情绪（促行动） | 消极情绪（抑行动） |
|---|---|
| 紧迫、义愤、希望、团结、YCMAD（我能做到） | 懒惰、冷漠、恐惧、疏离、自我否定 |

## 公共叙事三段论（Marshall Ganz）
| 故事 | 回答的问题 | 常见坑 |
|---|---|---|
| **我的故事**（Story of Self） | 我是谁？为什么在乎？为什么有能力？ | 不真诚（光吹自己多厉害） |
| **我们的故事**（Story of Us） | 我们是什么团体？共同传统与挑战？ | 不了解用户（凭空想象） |
| **眼下的故事**（Story of Now） | 为什么现在必须做？希望大吗？做什么？ | 只讲糟糕、不给希望 |

> 动员他人 = 策略（How）+ 故事（Why）。

## 英雄之路（约瑟夫·坎贝尔，13 元素）
```
平凡世界 → 召唤 → 拒绝 → 导师 → 跨越门槛 → 天助神力 → 护身符
→ 帮手 → 试炼 → 决战 → 战利品 → 返乡 → 荣归故里
```
- 重点写**努力的过程**（读者爱看成长，不爱看成就）。
- 障碍要**层层递进**；结局要**大团圆**。
- 皮克斯 4 条精华：重努力轻成就、共情读者、极简化、抛掉前五个想法。

## 完整流程：选题 → 写作 → 润色 → 传播 → 复用
### 选题（三要素 + 两来源）
- 三要素：**热度 × 产品契合 × 用户调性**（至少两项达标）。
- 来源：编译（Medium / Business Insider / Wired）、汇编（十大榜单）、原创（编译 / 汇编要尊重版权）。

### 写作（底层技巧）
- 六要素：时间、地点、人物、起因、经过、结果。
- 五感：味觉、触觉、视觉、嗅觉、听觉。
- 四个问题框架：用户肖像 → 改变什么行为 → 阻碍 → 制造什么情感。

### 润色（五方向 + 六情感 + 众包）
- 语言五方向：**简洁、清晰、通顺、统一、生动**。
- 情感六法：意外惊喜、征服快感、愧疚紧迫、身份优越、希望效能、义愤。
- 众包四要点：找对人、让对方说真话、节约时间、给回报。
- 大脑两模式：专注（咖啡茶 / 书桌）vs 发散（酒精 / 散步洗澡）。

### 传播（开场 10 秒 + 情感 + 找对人）
- **开场 10 秒**：标题、配图、开头段抓手。
- 病毒传播四大情感：**紧迫、义愤、希望、归属感**。
- **找对人（个别人物法则）**：内行、推销员、联络员（少数人撬动多数人）。
- 好故事结构：戏剧性目标 → 层层递进障碍 → 大团圆结局。
- 平台调性：研究各平台喜欢什么，投其所好。

### 复用（三方向）
- 旧文翻新、多媒介（图文 / 音频 / 视频）、多平台。

## 关键概念速查
| 概念 | 一句话 |
|---|---|
| 催产素 | 听故事分泌的「信任荷尔蒙」，故事力量的生物学基础 |
| 个别人物法则 | 内行 / 推销员 / 联络员撬动流行 |
| SUCCESs | 创意黏性六要素：简约、意外、具体、可信、情感、故事 |
| 空雨伞 | 现象 → 解读 → 行动 |
| MECE | 框架互斥且穷尽（朝此方向努力） |
| 原能力 | 可跨领域迁移的能力（提问、学会学习、批判性思考） |
| 指导方针 vs 算法 | 社科知识是 heuristics，不是保证成功的算法 |
| 摩天大楼战术 | 分析领域最好的故事，再往上加盖几层 |

## 可执行清单
- 动员 / 说服稿：Self / Us / Now 各写一段，自检三个坑（不真诚 / 不了解用户 / 只讲糟无希望）。
- 用「情绪决定行动」自检：结尾是否给出积极情绪（紧迫 / 义愤 / 希望 / 归属）？
- 润色用语言五方向 + 情感六法；发前找 1~2 人众包（让对方说真话、给回报）。
- 传播前检查开场 10 秒三件套：标题、配图、开头段。
- 找对人：确认谁是内行 / 推销员 / 联络员，优先触达。
- 用户调查：访问 6 人约得 85% 精确度（课程口径），别问「喜不喜欢 / 以后会怎样」。

## 反模式
- 只讲道理无故事（价值观没情绪，转不成行动）。
- 英雄之路只晒成就不写试炼（读者要成长过程）。
- Self 不真诚（光吹厉害）、Now 只讲糟无希望。
- 众包找错人 / 让对方说客套话 / 不给回报。
- 把社科框架当「算法」期待保证成功（实为指导方针）。

## 与其他课差异（若有）
- **偏运营 / 说服 / 品牌**；影视 / 短剧结构仍以查理十五步、孵化营为准。
- 与「brand-story-modes」强关联：正面模式是公共叙事的品牌应用分支。
- 与北大「故事 = 意外」互补：哈佛讲「为什么故事有用（信任 / 情绪）」，北大讲「怎么把故事写出来（结构 / 冲突）」。
