# CTFDP 与一句话故事
> 来源：十五步课；编剧孵化营（01 一句话故事、02 五种核心创意规律）
> 权威级别：P0
> 关联 Skills：topic.formula
> 关联 Agents：CoreHookAgent

## 一句话
选材用 **CTFDP**（角色/目标/幻想/困境/谜题，商业片最好复合两种）；一句话故事模型＝「一个**什么人**在**什么情况**下，仍然要**完成什么目标**」，目标是主动的，验证方式是讲给人听是否想知道后事。

## CTFDP：五种核心创意（选材工具箱）
编剧行话「**写什么比怎么写更重要**」——选材决定故事天花板。CTFDP 有两种用法：正向（从五类出发找创意）＋反向（已有创作冲动，用它判定属于哪类）。

| 字母 | 类型 | 规律（怎样才算好创意） |
|---|---|---|
| C | 角色 Character | 弱者（想知道他后来如何）/ 强者（特别技能/身份/血统）/ 组合（**两个全面相反**的人，或假身份） |
| T | 目标 Target | 目标**要么很诱人**（抢银行/盗墓/寻宝），**要么关乎生命**（家人/女友丢了）；最好是 mission impossible |
| F | 幻想 Fancy | 三条规则：符合**共同愿望** / 符合**共同担忧** / 对社会生活的**比喻**；**越幻想越要规矩**（瞎幻想≠想象力） |
| D | 困境 Dilemma | 四种：自然 / 人为 / 非自然（鬼屋）/ 体制；**角色越普通越好**（越普通越易共情） |
| P | 谜题 Puzzle | 核心＝**悬念**：把结果悬置，把「提问」与「解决」之间的时空悬置 |

- 困境、谜题**天然是好创意**：困境先天含对抗＋变数；谜题制造「没有答案的局」让人着急。
- 角色类判定关键：跟普通人差不多的角色，就不算「角色类创意」。

### 复合两种（现代商业片要求）
观众对故事强度要求越来越高，商业片最好**复合 CTFDP 中两种**：楚门＝F+D、哈利波特＝C+F、绝命毒师＝C+T。

## 一句话故事模型
```
一个【什么人】 + 面对一个【什么情况】 + 想完成一个【什么目标】
```
- **目标必须主动**且明确写进句子（很多人写到「什么情况」就停笔，不合格）。原因：观众本身缺乏内驱力，故事里的角色必须**内驱力爆棚**才打动人。
- **验证方法**：多讲给几个人听，看大家是否产生「想知道后事如何」的冲动。

## 十大设定模型（10 选 1～3，4 个是极限）
四个来自「什么人」、六个来自「什么情况」：

| 归属 | 设定 | 一句话 | 代表案例 |
|---|---|---|---|
| 什么人 | 困兽 | 牛逼的人被困住（虎落平阳） | — |
| 什么人 | 出水之鱼 | 小怂货离开舒适区（不称职的××，极限＝假身份） | 不称职的老师、假县长 |
| 什么人 | 壮举 | 过激行为/不可能完成的任务 | 《落叶归根》扛尸回家 |
| 什么人 | 人物关系 | 两个相反/水火不容的人捆在一起 | 《绿皮书》《恶人传》《触不可及》 |
| 什么情况 | 激励 | 把角色推出舒适区（「大人物遇小事，小人物出大事」） | 《疯狂的外星人》 |
| 什么情况 | 环境（困境） | 一个让主角极不适应的处境 | 《幸福终点站》《荒岛余生》《楚门的世界》 |
| 什么情况 | 规则 | 创造一套玩法（游戏/生死/时间规则） | 《鱿鱼游戏》《龙虾》、穿越 |
| 什么情况 | 赌局 | 收益与风险极大的目标 | 抢银行、孤胆英雄救女儿 |
| 什么情况 | 解密 | 一个谜题，跟着角色一起探究 | 探案、悬念、时间锁（《生死时速》） |
| 什么情况 | 对手 | 强大/神秘/未知的反派 | 《大白鲨》《侏罗纪公园》 |

## 目标六方向（6 选 1）
> 赢得 / 消灭 / 阻止·守护 / 逃离 / 送达·履约 / 救回·找回

## 三大新手误区（开课时先扼杀）
1. 追求「平凡而伟大的作者电影」——**先有作者再有作品**，先让观众认可你，顺序不能反。
2. 追求苦难/苍白/死亡气息——死亡崇拜是亚文化，撑不起主流影视。
3. 追求「写一个别人没写过的故事」——99.9% 都在重复前人，能换的是**元素**，不是「跳出框框」。

## 可执行清单
1. 写出一句话（什么人＋什么情况＋主动目标），标注命中的 CTFDP 组合与十大设定模型。
2. 用目标六方向锁定「主动目标」，避免只写「什么情况」就停笔。
3. 验证：讲给 2–3 个目标受众听，看是否产生「想知道后事」的冲动；连朋友都打动不了就放弃。
4. 检查设定是否堆太满（10 选 1–3，4 个是极限；不叠加「双重巧合」）。

## 反模式
- 追求「别人没写过」；把死亡/苦难/苍白当主流高格调；先冲作者电影。
- 目标被动、无内驱力；一句话故事停在「什么情况」缺目标。
- 设定堆满（双重巧合）；穿越/设定形式上过分创新而非下功夫在剧情。

## 与其他课差异
- CTFDP（十五步）与十大设定模型（孵化营）是两套选材工具，但同源：CTFDP 的 C≈「什么人」四设定、T/D/P≈「什么情况」六设定、F 横跨两者，实际创作可互为印证。
- 一句话故事作为选题入口，与 `topic.formula`、`topic.market_brief` 关联；落到故事结构用 `14-story-craft/fifteen-steps.md`。
