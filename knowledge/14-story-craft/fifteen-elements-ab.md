# 十五元素与 AB 故事
> 来源：查理老师的编剧孵化营 / 全课程核心精华（04–06 故事的内核和要素 1–3）
> 权威级别：P0
> 关联 Skills：struct.*
> 关联 Agents：WritingOrchestrator

## 一句话
故事 = 环境 + 人物 + 事件 + 主题（共 15 个元素）；A 线＝Want（外在欲望/事件线）、B 线＝Need（内在需求/成长线），**不要叫主副线**——一个讲「事」、一个讲「人」。

## 内核三要素（故事为何精彩）
| 内核 | 说明 |
|---|---|
| 冲突（对抗） | 故事核心；分**外部对抗**（有敌人）＋**内部对抗**（自己有缺陷挣扎），商业片二者缺一不可 |
| 变化 | 关键；指**有效变化**——观众「期待以外」的变化＝角色「能力以外」的变化（吃出一只蟑螂才是戏） |
| 共情 | 邀请观众进入故事；分「与人共情」＋「与情境/世界共情」，方法靠真实感＋合逻辑 |

- 商业级对抗五特点：**可视化 / 激烈 / 有危险赌注 / 有发展升级 / 有意外**。

## 十五个小元素（四大模块）
```
环境（世界观）= 时空 + 规则
人物（主角）  = 身份 + 缺陷 + 境遇 + 目标 + 行动
事件          = 核心问题 + 阻力 + 转折 + 代价 + 结果
主题          = 正价值 + 附加值 + 成长
```

### 环境：时空 + 规则
- **时空＋规则＝世界观**；同一时空可写不同规则（当下既可写「众志成城」也可写「贫富悬殊」），规则是观众进入片子的第一步。
- **大环境 vs 小环境**：故事的环境特指「主角所在的环境」。主角往往与大环境**格格不入**，但缩在自己的**小环境（肥皂泡）**里与大环境和解——泡踩在边缘，很快被境遇戳破。
- 非真实环境必须「合理」＝**真实生活的比喻**（楚门＝大数据监控的比喻；雪国列车＝阶层固化的比喻）。

### 人物：身份 + 缺陷 + 境遇 + 目标 + 行动
- **身份**：与主事件最相关的外化标签（程勇＝开药店小老板）。
- **缺陷**：内在缺陷（不是「缺陷」字面，广义上可用「缺失」），是成长要补的窟窿、内部对抗的来源。
- **境遇**：戳破肥皂泡的针——**机遇**（往上走：吕受益来报信）或**遭遇**（往下走：女儿被抓）。
- **目标**：主动、明确、最好**mission impossible**；用**三个为什么**立住：为什么是他？他为什么去？为什么是现在？
- **行动**：采取**最激进、最大程度**的行动（生活里人保守，故事里主角替你激进）。

### 事件五要素
| 要素 | 说明 |
|---|---|
| 核心问题（钩子） | 这件事能不能办成？是最大悬念/钩子 |
| 阻力（三座大山） | 环境 / 对手 / 自身；对手四规矩（明确的人、出场越早越好、有步骤计划、针锋相对） |
| 转折 | 1500 字里必须有转折，多为意外、多往坏的方向变 |
| 代价 | 必须付出，伴随**死亡气息**（最好真死人；世界观不允许就广义「蜕变/重生」） |
| 结果 | **行动失败，目标达成**（绕过动作实现欲望；西游记取到假经却普度众生） |

### 主题三要素
- **正价值**（正义/爱/帮助）战胜 **附加值**（仇恨/计较/冷漠/遗忘）——开头附加值占优，过程正价值逐步战胜。
- **成长**：扛在主角身上，起点是什么→终点是什么。缺陷是成长空间，代价是成长代价。

## 三个高阶概念
1. **原罪**：缺陷不够具体时，用「原罪」承担（《落叶归根》老赵劝酒致工友死；《肖申克》安迪自认不称职丈夫）。
2. **放弃爱情**：与「死亡」几乎同当量的牺牲（《落叶归根》老赵放弃与宋丹丹的爱情）。
3. **概念化达成**：目标不以字面方式达成，而是概念化达成（「家不是地址，有爱的地方才是家」）。
4. **在对手身上发现自己**：刺激主角成长的关键一招（印度妈妈发现老鸨说的话与自己逼女儿的话一模一样）。

## AB 故事
| | 英文 | 含义 | 对应元素 |
|---|---|---|---|
| A 故事 | Want | 外在欲望、事件线（想要什么，往往较虚幻） | 目标 |
| B 故事 | Need | 内在需求、成长线（真正需要什么） | 缺陷/弥补缺陷 |

- **多数故事「先 A 后 B」**：先追 Want，最后才发现真正需要 Need；**《肖申克》反其道「先 B 后 A」**（先内心赎罪，再越狱）。
- 案例：药神 A＝搞药救别人，B＝救自己（成「神」）；落叶归根 A＝送死人回家，B＝送活人回家。

## 人物弧光 vs 催化剂主角
- **人物弧光**＝角色内在成长过程；弧光拉得越满故事越完整、口碑越高（已成本级刚需，很多公司拿「有无成长」当筛选门槛）。
- **催化剂主角**＝主角自己不变，但**催着所有其他人成长**（《落叶归根》《疯狂的麦克斯》《阳光小美女》）。
- 喜剧描绘「改变」（易拉弧光），正剧描绘「坚持」（可无弧光）。

## 可执行清单
1. 用 15 元素顺序写 1500 字梗概：环境→人物→事件→主题，缺一不可。
2. 大纲页同时写出 **A 线目标（Want）** 与 **B 线需求（Need）**；每场戏问自己：推进的是 Want 还是 Need？
3. 目标用「三个为什么」自检；结果按「行动失败、目标达成」设计（或概念化达成）。
4. 成长写清「起点是什么、终点是什么」；代价落到实处（死人/放弃爱情/蜕层皮）。

## 反模式
- 只有动作没成长（无 B 故事），或只有鸡汤没事件（无 A 故事）。
- 「有效变化」写成无效变化（把一碗饭一口口吃光）；转折一条道走到黑；代价不痛不痒无死亡气息。
- 把 AB 故事误当「主副线」；不会用「行动失败但目标达成」「概念化达成」就先别硬上。

## 与其他课差异
- 十五元素是孵化营「概念→梗概」的展开工具，与十五步（故事结构骨架）互补：十五步管「顺序与转折」，十五元素管「内容与要素」。
- AB 故事与 `05-character/` 人物塑造（弧光/催化剂）同源；落到节拍用 `14-story-craft/four-act-beats.md`。
