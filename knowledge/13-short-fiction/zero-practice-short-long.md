# 0基础实战：短篇与长篇衔接（冲突·大纲·人物·情节·价值观）
> 来源：0基础小说创作实战课短篇和长篇故事（F4 四位讲师，27 节，全课程核心精华 + 知识体系）
> 权威级别：P1
> 关联 Skills：struct.outline, char.bible_big5, topic.value
> 关联 Agents：WritingOrchestrator, CharacterBibleAgent

## 一句话
这门 F4 实战课讲「从认知到成稿」的全链路：先认清行业与心态，再用「冲突—反派—高潮」搭动力系统，用「大纲—细纲—人物—情节—价值观」搭骨架血肉，最后靠套路模板落地；短篇练构思、长篇靠大纲，两者靠「先验证冲突再开长篇」衔接。

## 课程总纲（一条递进主线）
```text
认知篇（认清行业/选入口/摆心态）
   → 内核篇（冲突·反派·高潮 = 小说动力系统）
   → 框架篇（立意·设定·结构 = 长篇骨架）
   → 人物篇（谁来演·怎么立·怎么变）
   → 情节篇（8条线索）
   → 价值篇（价值观/世界观）
   → 成稿篇（第一部小说 + 套路模板 + 懒人包）
   → 收尾篇（打磨·修改·坚持）
```

## 两条底层认知
### 1. 认清时代：往钱多的地方去
| 维度 | 传统小说 | 网络小说 |
|---|---|---|
| 载体 | 纸质/不考虑载体 | 手机（屏幕小→情节抓眼、逻辑一眼看懂） |
| 篇幅 | 六七十万字顶天，重文学性 | 普遍很长，服务读者付费 |
| 更新 | 写完再出 | 定时更新，养成读者习惯 |
| 定位 | 文学性优先 | 读者欢迎度优先 |

- 新人三条路径：**网络文学**（起点/创世/晋江/掌阅/17K，BAT/小米/网易已入场）、**新媒体写作**（公众号连载，终极形态「你就是 IP」）、**传统文学**（重文学性，有三大弊端，两派终将融合）。
- **IP = 你的影响力半径**；「小说是影视圈的上游」。

### 2. 摆正心态：写作是可学的技术
- 文笔是练出来的不是天赋（唐家三少《光之子》→《龙王传说》十三年对照）。
- 市场「允许你犯错」；需要**钝感力**（渡边淳一），扛退稿/比较/数据焦虑；史蒂芬·金「写完别急着改，最大的敌人是自己」。
- 心法闭环：敢开始 → 能坚持（第1–3节讲风口机遇，第26–27节讲修改坚持）。

## 内核篇：冲突·反派·高潮（动力系统）
### 冲突（四种类型，自查清单）
> **冲突 = 打破「本应维持的现状」。**
| 类型 | 说明 | 案例 |
|---|---|---|
| 情感冲突 | 爱恨纠葛 | 乔峰与马夫人、吕布董卓貂蝉 |
| 利益冲突 | 争夺资源 | 绝世好剑、智取生辰纲 |
| 性格冲突 | 性格不合 | 悟空八戒、鸣人佐助、聂风步惊云 |
| 观念冲突 | 价值观对立 | 法海白素贞 |

### 反派（把冲突落地的工具）
- **第一层：脸谱化反派**——核心技巧「泼脏水」；效率原则「怎么又是你」。
- **第二层：读者愿意接受的反派**——有深度、有逻辑（我爱罗、东方不败、成昆、李莫愁）。
- 反派分量决定高潮的快感。

### 高潮（四种，只需精通其一）
> **情感高潮 / 性格高潮 / 打斗高潮 / 主题高潮**（纠正误区：高潮 ≠ 打架）。

## 框架篇：大纲与细纲（长篇骨架）
- **大纲本质**：写大纲不是目的，**了熟于心才是**。
- **小说立意 = 两根支柱**：
  1. 主角的追求（代入感/结尾预判/渲染美好；四抓手：金钱/权势/力量/爱情）
  2. 主角的处事方式（靠情节阻力体现）
  - 三条铁律：激发作者向往、保持纯粹。
- **世界设定**：新人别自创世界，**借壳改名**；等级设定**不超 10 个**。
- **人物设定**：背景三类型（创伤/温情/小透明）+ 三种生活状态（职业/个人/私生活）。
- **大纲两个基本点**：明确目标（终点）· 知道何时填坑（管理伏笔）。
- **细纲两种写法**：章节型（逐章列点）vs 高潮型（只标高光点）。
- **编辑判断三条线**：因果宿命线 / 冲突线 / 感情线。

## 人物篇（核心原则速查）
| 原则 | 一句话 | 案例 |
|---|---|---|
| 废人物不写 | 没作用的人物就删 | 水浒卖梨小哥 |
| 少用巧合 | 追求「必然性」 | 林冲 |
| 用行动说话 | 不用形容词 | 肖申克、盖茨比 |
| 选择符合身份 | 社会常识/价值观/身份三层逻辑 | — |
| 命运要「不得不」 | 人物自动化 | 萧峰 |
| 每个举动可解释 | 读懂背后逻辑 | 王熙凤 |

- **人物来源**：先想好「谁来演」（给具体形象）；现实根基 = 自我投射 / 身边人杂糅 / 典型人物。
- **人物关系三维度**：情感 / 友情 / 敌对（突发情绪 ≠ 人物关系）。
- **人物大转变两要素**：大事 + 影响。
- **人物小传**：防止「写跑」，画像法/清单法；史诗式必须写，片段式可省。

## 情节篇：8 条线索
- **误区**：情节不是越离奇越好（凶杀/同性恋/阴谋论/外星人/一场梦都是坑）。
- **创新 = 旧元素的新组合**；可借经典模式（亚里士多德4种、赫尔曼9大模式、普罗蒂36种戏剧情境）。
- **倒推法**：先预设结局，再倒推过程。
- **8 条线索**：四大基本线（成长线/爱情线/家庭线/回忆线）+ 荡开一笔四法（小故事/评论/追忆/闯入者身份揭秘）。
- **新手入门法**：掐头去尾（《上海滩》许文强）。
- **终极心法**：从念头驶向愿望。

## 价值篇：价值观/世界观
> **情节和人物容易撞车，价值观抄不走；先有价值观，再有人物和故事。**
- 写自己价值观的三点好处：顺畅 / 有话说 / 不自相矛盾。
- 价值观类型光谱：日常写实 → 普世价值 → 体育励志 → 史诗 → 哲学。
- 强价值观小说家：亦舒 / 安妮宝贝 / 张爱玲。
- 结论：每一部小说记录的都是你当下的价值观。

## 成稿篇：第一部小说 + 套路
### 动笔顺序
```text
题材类型 → 一句话故事 → 故事梗概 + 人物总谱 → 塑造主角
```
- 情节四要素：开端（四作用）→ 发展（大冲突套小冲突）→ 高潮 → 不可逆结局。
- 破解卡文：**从后往前推**。

### 两大底层套路 + 懒人包
- **大卫打倒歌利亚**（弱者胜强者）、**罗密欧与朱丽叶**（爱情受阻）。
- 都市小说套路：主题 + 喜剧结尾 + 正能量铁律。
- 爱情小说套路：人物设定模板 + 四层冲突来源 + 危机救援 + 圆满发糖。
- **36 种戏剧情境**（乔治·波尔蒂）——短篇「懒人包」。
- **短篇五步流程**：灵感 → 摘要 → 转折 → 写作 → 修稿。

## 收尾篇：无需文笔 + 修改清单
- 文笔不是初学者的第一要务，**人物才是小说成败关键**（「酵母/材料」比喻）。
- 人物三度空间：生理 / 社会 / 心理。
- 主角必须执着；配角也要丰满（福尔摩斯与华生）。
- 「好小说里的人物都有病」（贝微微/黄小仙/李雪莲）；找活人当模特。
- 修改清单：少用网络用语；砍掉无用对白；海明威 39 遍修改。
- 灵感三大来源：经验 / 灵感 / 想象力。

## 短篇↔长篇衔接（本课核心落点）
- 短篇练**命题构思**、长篇靠**大纲落地**。
- 衔接法：开长篇前，先用短篇验证核心冲突/立意是否成立（省去无验证直接百万字开书的成本）。
- 三要素总纲：人物 + 情节 + 价值观，所有单节都在拆这三块。

- [ ] 长篇前写：立意两根支柱 + 世界借壳改名（等级≤10）+ 人物背景三类型 + 细纲（章节型/高潮型）。

## 反模式
- 无验证直接百万字开书（短篇都不写就上长篇）。
- 情节堆离奇（凶杀/阴谋论/外星人/一场梦）当创新。
- 人物没作用硬留着；用形容词代替行动描写。
- 新人自创宏大世界观，不借壳；等级设定堆到十几种。
- 一上来求文笔，忽略人物（本末倒置）。
- 网文长篇不写大纲（必崩，与红娘子口径一致）。

## 与其他课差异
- 本课是「结构—人物—价值观」的创作层全链路，红娘子/0基础偏「市场—定位—变现」运营层，两者互补（变现见 10-ops/hongniangzi-submit）。
- 冲突四类型/反派两层/高潮四种与九格权威表、狂更猫可交叉印证；本课更强调「价值观抄不走」与「人物三度空间」。
- 大纲「立意两根支柱」与写作课程2「珍珠串项链/逆推法」同向（先定目标再回溯），详见 04-webnovel/xiezuo2-pearl-and-twist。
