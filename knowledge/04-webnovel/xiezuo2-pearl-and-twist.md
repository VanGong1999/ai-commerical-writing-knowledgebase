# 珍珠项链结构与反转层次（写作课程2）
> 来源：写作课程2（讲师小璇，19 节，全课程核心精华 + 知识体系）
> 权威级别：P1
> 关联 Skills：struct.outline, struct.twist
> 关联 Agents：WritingOrchestrator

## 一句话
写小说先让人看懂、再让人看爽、最后让人记住（立意）；把独立小事件像珍珠一样串在单一主线上（阴珠压抑/阳珠爽交错）；反转分三层且先定目标再填剧情。

## 最核心的一句话与底层心法
**先让人看懂，再让人看爽，最后让人记住（立意）。**

| 心法 | 含义 | 复用场景 |
|---|---|---|
| 写「1」脑补「2、3」，删「4、5、6」 | 只写最有信息量的一句，其余留读者脑补或删掉 | 开头/正文/视频节奏通用 |
| 用词精准 → 文学素养 → 立意深远 | 好文笔不是华丽，是精准简洁 | 见 precise-prose |
| 写自己会的，不碰瓷没经历的人性 | 没穷过别写穷，没驾驭力别硬写新设定 | 立意/人设 |
| 从套路中出新 | 借助熟悉的东西重新排列，非凭空创造 | 结构/反转 |
| 张弛有度 | 武侠不能从头打到尾，种田不能从头种到尾 | 节奏/高潮 |

## 大纲：珍珠串项链 + 逆推法（第2课）
- **大纲 = 框架**：聚焦主线、提前避雷、知道写什么。
- **两种作家类型**（桑德森）：
  - **探索型**：目标坚定 + 后纲系统（边写边问「脱离主线了吗？踩雷了吗？坑填了吗？」）。
  - **大纲型**：目标清晰但框架别太细，留操作空间。
- **珍珠串项链**：把独立小事件串在主线；**阴珠子（压抑）与阳珠子（爽）交错**，制造节奏起伏。
- **逆推法**：站在高潮回溯「为了干成它需要什么」，提前埋装备、人物、关系（与反转「先定目标」同思维）。
- **避雷**：情绪 / 取舍 / 高潮 / 要素重复。

## 开头：黄金一章 / 第一句话（第3课）
- 读者只给约五六百字耐心 → **黄金一章、第一句话**决定去留。
- 核心 = 主角 + 故事性（期待感）。
- **一句话公式**：`类型 + 主角 + 矛盾点`。例：「我是总裁夫人，但总裁不爱我。」
- 打脸要有**持续性和升级空间**：别一次打死渣男，爽的同时抛新鱼钩。

## 中途卡壳（第4课）
- **草蛇灰线**：卡文时回看之前「留白」，二创填补空白（读者以为早铺垫好）。
- **打破常规**：不影响主线前提下，打破读者和作者自己的预设。

## 高潮：马斯洛需求波峰（第12课）
- 用**马斯洛五层需求**（生理/安全/社交/尊重/自我实现）制造波峰。
  - 小高潮 = 单需求满足；大高潮 = 多需求同时爆发 + 最高思想内核。
  - 小高潮可多，大高潮 1–2 个放中后期。
- **黄金比例**：暗示 30% + 意外 60% + 意外的意外 10%。
- 三不：别重复相邻高潮、占领道德制高点、焦点聚焦主角。

## 反转：三层 + 先定目标（第13课）
| 层 | 类型 | 说明 |
|---|---|---|
| 1 | 常规设定（小反转） | 约定俗成套路内的反转 |
| 2 | 现实反常识（小反转） | 打破常识预设 |
| 3 | 故事结构明暗线（大反转，1–2次） | 明线暗线交汇的颠覆 |

- **先定反转目标**，目标之间填剧情（与逆推法同构）。
- 写小说必须**眼高手低**：眼界高于手才能进步。

## 可执行清单
- [ ] 大纲检查：主线珍珠列表（阴/阳珠子标注）+ 避雷四项。
- [ ] 开头用「类型+主角+矛盾点」一句话公式自测，第一句话即给期待感。
- [ ] 打脸设置升级空间，每处爽点埋新鱼钩。
- [ ] 高潮按马斯洛五层标注需求波峰，黄金比例 30/60/10。
- [ ] 反转先定目标表（三层各定几个），目标间填剧情。
- [ ] 卡文时回填「草蛇灰线」留白，或主动打破常规。

## 反模式
- 从头打到尾无张弛（缺阴珠/阳珠交错）。
- 相邻高潮重复（爽点同质）。
- 开头温吞、第一句话不给「类型+主角+矛盾」。
- 反转无目标、为反转而反转。
- 写「没嘴人」、行为不合逻辑（详见 xiezuo2-character-tricks）。

## 与其他课差异
- 与 0基础大纲层级互补：0基础强调「立意两根支柱/细纲」，本课强调「珍珠串项链/逆推法/反转目标」。
- 「逆推法」与 0基础「倒推法/从后往前推」同构，可互相印证。
- 冲突/爽点仍以零基础+狂更猫+九格权威表为准；本课的爽感七分类见 05-character/xiezuo2-character-tricks 或 precise-prose 联用。
- 立意/IP 是写作课程2 的收口（立意=成绩好+口碑好的共性；IP=产品IP+个人IP），需独立展开时另设条目。
