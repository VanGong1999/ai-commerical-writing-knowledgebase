# 零基础高阶：热销拆解方法论
> 来源：小说零基础写作班 / 44–49（高阶热销：人设/团队/情节/构思/开篇/男频；方法论合并，非逐课案例抄录）
> 权威级别：P0
> 关联 Skills：dissect.*, hook.*, char.*, struct.*
> 关联 Agents：DissectAgent, TropeMineAgent, CoreHookAgent

## 一句话
热销拆解只学可迁移机制：构思「想法→立意→预设」、人设「三维空间」、开篇「切入三路」；拆完要能说出「它靠什么赚钱、凭什么被点进来」，禁止扒大纲换皮。

## 1. 构思三阶（想法 → 立意 → 预设）
| 阶 | 定义 | 关键动作 |
|----|------|----------|
| 想法 | 萌芽（「想写个爱情故事」） | 拆成人物/情节/台词，模糊想法追问扩展 |
| 立意 | 引入冲突后的戏剧骨架（「爱情 × 末日 × 为救变异人类而存在」） | 用「如果……将会……？」逼出悬念与利害 |
| 预设 | 在骨架上长血肉（角色+冲突+结论） | 人物介入 = 立意转预设的本质 |

- **好立意三问**：① 是否含近期爆款元素？是否超过约三点（过载）？② 能否让读者产生具体期待？③ 欲望三角——主角要什么/为何要/遭什么阻碍？
- **预设两问**：故事关于什么（=故事缩写+核心冲突+人性实验）；角色身上会发生什么、主视角是谁（同素材换视角＝换故事）。
- 无预设＝无路标旅途遍地死胡同；预设负责组织想象，只让「特定部位长肉」。
- 立意越满下笔越不空；但女频篇幅相对易想结尾，男频数百万字只能定最终方向/前几卷方向，不必前期想尽。

## 2. 人设拆法（三维空间，非文学仿写）
| 维 | 含义 | 用途 |
|----|------|------|
| 一维 | 纸面直观：外貌/身份/行为动作/语言，脸谱化性格 | 开篇速立即可（女频可强，男频只需一两百字拎清） |
| 二维 | 用事件、行为、语言堆积（身世/金手指/性格成因） | **男频主战场** |
| 三维 | 心魔/世界观/伴侣观等 | 可选；想不到可省，很多热销无心魔 |

- **写满两维已吊打八九成网文**；热销小白常只有一维+二维一点。
- **快速立体**：一段甚至一两百字可同时立一维外貌 + 二维身世金手指 + 三维主动抉择。
- **开篇先脸谱化**：主性格清晰标签（阿翡=冷+桀骜+倔强），次性格多数书没有，前期勿堆复杂。
- **一维文字写法**：外貌分散、多视角、动态（长而不细/眼尾弧度），忌「大有神水汪汪」静态套话；用动词密集出动态画面感与烟火气。
- **二维=卖当下品质 + 为后文成长铺垫**：把每件大事标「情节功能/人设卖点/铺垫」。
- **团队四套路（45）**：冲突 / 互补 / 镜像 / 反差；反派更坏或镜像成就主角；拆书学「思路与人设亮点」，情节来自人物。

## 3. 成长 vs 转变（男频核心，49）
| | 成长 | 转变 |
|--|------|------|
| 含义 | 能力/力量体系升级 | 性格→行事风格改变 |
| 难度 | 好写、天天写 | 很难，写好=经典，写砸=扑街 |
| 读者 | 接受升级 | 无耐心看大起大落虐点，易成堵点 |

- **主性格稳定，次性格可感变化**（贪财/自私/怕死等普通缺点作亮点，本心善良正直可不变，变的是行动）。
- 转变是**一级级累加**（刚见一面的牺牲不够，朋友级赴死才完成），负面情绪与等级/感悟同步加深。
- 重生/末日：开篇已是成熟稳定性格，惨过去几句话带过，勿十几二十章卖惨。
- 《大奉》是另一种「变」：身份而非性格——棋子→自由棋子→棋手。

## 4. 开篇拆法（为何被引进去，48）
- 三大吸引力：**设定**（吃脑洞）/ **情节**（本课主攻：冲突悬念文本化）/ **文笔**。
- **切入三路**：矛盾冲突式（尖锐事件施压）｜绝境式（开篇即绝境）｜悬念式（多疑点追答），可叠加。
- **穿越四点**：穿越前少写；死因一句话；前情须有效信息且后文起作用；可直接切入穿越后。
- **穿书先知=金手指也要压迫**（系统卡死黑化节点），否则脱离原著=普通穿越。
- **压迫技巧**：任务问「完不成怎样/完成怎样」，后果须与主角强相关（多与生死挂钩）。
- **节奏**：问题提出到解决一般≤约 3 章（女频可一章内）；男频主线全貌或需约 100 章后才清，前十章只见冰山一角；解决后勿塞无关过渡。

## 5. 男频女性角色（49）
- 三大作用：① 制造爽点（必须美、类型多样；调查口径「温柔姐姐>御女>萝莉」，以当期为准）② 可倒贴（男主姿态高级勿油腻）③ 对男主能力的**正反馈**（价值增长必须说出来）。
- AB 版测验：男主赢了须得崇拜等正向反馈（目光炽热/结巴问实力），「赢了还被女生嘲」= 大堵点。
- 女主情感转变不靠喊爱：小动作藏小心思（留一枚铜钱在手心），彼此相爱不油腻。

## 6. 情节结构（46）
- 情节基础＝矛盾冲突；三幕式（起承转合）可嵌事件级小结构。
- **英雄之旅 12 阶段**（平凡世界→召唤→…→归来）：大男主/大女主通用；「正常世界」依故事类型定义（浪子回头故事里可能是放浪日常）。

## 可执行清单
```text
选对标热销 → 立意三问填空 → 预设两问填空
→ 三维人设表（能拆多少算多少）→ 标「成长 vs 转变」
→ 开篇归类（冲突/绝境/悬念）→ 标压迫与章末钩子
→ 写「可迁移机制」一句话 → 禁止整本换皮大纲
```

## 反模式
- 逐课复述案例剧情当知识库；只贴「有悬念」标签。
- 神话开类型；为创新穷举到不可写。
- 男频硬抄一维美文人设；新手硬拆文学性强的大神文短期用不了的宏大叙事。
