# 男频升级流循环
> 来源：狂更猫 / 03、20、44、51；零基础 / 39、46、49
> 权威级别：P0
> 关联 Skills：male_long/upgrade-loop, male_long/gold-finger-cap
> 关联 Agents：WritingOrchestrator / MaleUpgradeLoopAgent

## 一句话
男频中长篇靠「固定金手指 + 目标迭代」循环推进；单循环走压抑→爆发→打脸→新目标，升级是爽点通道而非爽点本身；人设走「成长（能力）为主、次性格可感转变」，主性格稳定。

## 循环三要素与加强版
- 循环三要素：**主角目标 + 金手指 + 核心爽点来源**；主线 ≠ 核心（升级是来源，不是爽点本身）。
- 长篇本质是套路重复；学会写一个合格循环 ≈ 能撑 30 万 / 100 万字的骨架能力。
- 单循环 SOP：拉目标 → 给逻辑 → 设阻碍 → 围绕核心制造**有关系的对比爽点** → 奖励快速展示 → 用新阻碍/误会/期待续到完成 → 结算 → **新目标**。
- 第 N+1 循环 = 第 N 循环加强版（敌阶、赌注、见证层级、信息差厚度至少抬高一项）。
- 不是「报复成功一个人 = 一个循环」；循环终点应对齐阶段目标与总主线倒推点。
- 三万字倒推法：定终点震惊点 → 倒推章纲 → 第二循环加强版。

## 男频人设：成长 vs 转变（零基础 49）
| | 成长 | 转变 |
|--|------|------|
| 含义 | 能力/力量体系升级 | 性格→行事风格改变 |
| 难度 | 好写、天天写 | 很难，写好=经典，写砸=扑街 |
| 读者 | 接受升级 | 无耐心看大起大落虐点，易成堵点 |

- **主性格稳定，次性格可感变化**（贪财/自私/怕死等普通缺点作亮点/笑点，本心善良正直可不变，变的是行动）。
- 转变是**一级级累加**（刚见一面的牺牲不够，朋友级赴死才完成），负面情绪与等级/感悟同步加深。
- 重生/末日：开篇已是成熟稳定性格，惨过去几句话带过；若要虐，开局性格须「可虐」，太坚毅则虐不起来。
- 《大奉》是另一种「变」：身份而非性格——棋子→自由棋子→棋手。
- 男频人设主战场在二维事件：用行为与事件堆积可信优势，而非一维美文空转。

## 情节结构补充（零基础 46）
- 情节基础＝矛盾冲突；三幕式（起承转合）可嵌事件级小结构。
- **英雄之旅 12 阶段**（平凡世界→召唤→…→归来）：大男主通用；「正常世界」依故事类型定义（浪子回头故事里可能是放浪日常）。

## 反模式
- 无目标空想剧情；强扭人设圆作者意图。
- 把境界数字涨一级当爽点；无对比的发奖励。
- 敌人战力断层过大导致无过程碾压；无效对比（旁人与主角无关）。
- 展示奖励拖沓；偏离核心的支线大写特写。
- 开篇十几二十章卖惨写性格转变（新手易成堵点）。
