# 男频金手指：限制、成长与推剧情
> 来源：小说零基础写作班 / 39；狂更猫 / 04、20、25、44、51
> 权威级别：P0
> 关联 Skills：male_long/gold-finger-cap, male_long/upgrade-loop
> 关联 Agents：WritingOrchestrator / MaleGoldFingerCapAgent

## 一句话
金手指把不合理合理化：少而可延伸、弱开有成长；用固定规则反复解决问题，并在解决后制造新问题以驱动循环。

## 底线与矛盾
- 底线（零基础 39 三共性 + 狂更猫）：能说清能干嘛 / 不能干嘛；少；可延伸；开局弱到有成长空间；服务核心爽点且逻辑自洽。
- 与主题/背景碰撞出矛盾：禁区、代价、冷却、暴露风险——摩擦即剧情，不是设定百科。
- 零基础四方面想设：从作用/来源/规则/成长四方面想，再查三共性底线。

## 循环视角
- 目标与金手指是全书最需认真对待的两件事；循环 = 用**固定**金手指反复解决问题的思路。
- 推进写法：制造配合金手指特殊性的问题 → 内心思考如何用 → 行动解决旧问题 → 副作用/新问题 → 读者预知下一层能力或更大画饼。
- 「未发生时更爽」：过程可压缩，但关键决策与限制必须可见；画饼后要有阶段性兑现，忌无限空饼。
- 成长阶：按卷/循环解锁，禁止跨阶瞬满；禁止每遇阻碍新开互不统属外挂（规则膨胀）。
- 开篇义务：系统/金手指须说明能干嘛，并尽早介入事件；忌贴皮解说完不进行动。
- 跟风避撞：对标书若切入点像、金手指类似、第一章结构相似，三项里至少改透两项。

## 万能系统模板（狂更猫 66，可迁移）
- 模板 A：面板加点 + 人气值买技能（逼每个剧情造声势）。
- 模板 B：人气/震惊/破防/负面情绪值 + 抽奖。
- 启示：系统可「永不激活」只钉住场景，勿「逃成功拿五千万」式一锤子结局。

心理推进口诀（主视角）：所见 → 五感 → 思考 → 金手指问题 → 再行动。

## 反模式
- 又多又满级开局；万能解一切冲突。
- 规则无限叠、多系统互不统属；金手指替代角色思考。
- 贴皮不进行动；只加设定不加摩擦。
- 用金手指替代「对比打脸」——有能力无场面仍不爽。
