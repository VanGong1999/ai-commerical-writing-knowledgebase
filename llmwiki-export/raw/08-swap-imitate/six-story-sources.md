# 换元法六大元素与一度/二度置换
> 来源：九格 / 换元法.txt；3.md
> 权威级别：P0
> 关联 Skills：swap.master, swap.*
> 关联 Agents：SwapDiagnoseAgent, SwapPlanAgent

## 一句话
一切可换元创新建立在六源诊断：**事件、结构、主体（价值观）、背景、人物、道具**；一度置换只换背景/人物/道具（换皮不换骨），二度置换必换核心事件（换骨）。

## 六元素详解（从「六」往「一」理解）
1. **道具**（最容易理解）：承载意义的角色——象征性意义或功能性的物品（金手指、系统也算）。**路人甲也属道具**（气氛组「哇好厉害好牛逼鼓掌」）。主角/配角/路人甲最大区别是「有名字和没名字」：主角一个、配角有名字（张三李四）、路人没名字属环境。配角存在意义 = 为情节发展产生 / 塑造主角弧光 / 推动剧情，否则没存在意义。
2. **背景**：时间、季节、地点、社会制度（架空/幻想/现实/年代；中式/西式；外太空「一年实为十年/千年」）。背景影响故事走向。
3. **主体（价值观）**：文章的价值观。世情文价值观**只需普适即可**（爱情、权利、生存），换元时主体变来变去变得不多。
4. **人物**：分静态/动态（有人物弧光，大部分动态）。设计最关键两点——**三位一体（基础）**：背景决定性格、性格决定行为（富家翁娇生惯养→霸道合理；穷苦人家性格强势→行为懦弱就出戏有 bug）；**反差（差异化）**：在三位一体上做反差、做记忆点。
   - **人物三字经**：① 人物皮加缺点（主角要有记忆点，或一个不痛不痒的缺点，致命缺点不行）；② 配角弱加特征（纯工具人配角加点特质）；③ 显身份服饰定（身份高低从服装体现）；④ 微起伏写成长（主角牛不牛不是自己说，是配角衬托）；⑤ 记忆点口头禅（《大奉打更人》「勾栏听曲」、《美少女战士》「代表月亮消灭你」、《火箭队》口头禅——反派配角出场两三分钟人物就立起来）。
5. **故事**：承载期待感与情绪、情绪共鸣的主要载体。**故事 + 结构合占约 60%（各 30%），是及格线**；在此之上再看人物弧光。故事是一层层累加，不是一个事件讲完所有事。
6. **结构**：叙事视角——**99% 短篇第一人称、长篇第三人称**；多视角不要写（群像文多年能爆款的屈指可数）。时间线——非悬疑题材基本顺序/倒叙/插叙，**短篇 90% 线性顺序**；悬疑题材时间线非常复杂（非线性/多段/穿插/环形/因果循环，如《恐怖游轮》），**不要一上来写悬疑**。

## 一度置换 vs 二度置换
| | 一度置换 | 二度置换 |
|---|---|---|
| 换什么 | 只换背景、人物、道具（最常用背景+人物），**不换核心故事** | **必换核心事件（故事）**，背景人物道具联动换；主体换得不多 |
| 对应 | 行业「粗纺/精纺」 | 换骨 |
| 相似度 | 高（两篇对比「其实差不多」） | 低（「看起来不是太像」） |
| 适合 | 新人 | 留级/进阶（核心事件换得好需积累素材+蹭热点） |
- 二度置换难点：**AI 出来的核心事件往往老套**，需要自己积累情节、蹭热点、融合素材。

## 节奏量化（通用标准，短篇）
| 指标 | 标准 |
|---|---|
| 章节数 | 约 12 章 |
| 每章字数 | 约 800 字 |
| 每章情节点 | 6~8 个 |
| 每个情节点字数 | 50~200 字 |
- 团队挑了**大几千本书**做量化，发现大部分书节奏差不多，可总结通用节奏。**仿写时按这个量化标准仿**：「他多少章节你多少章节，他多少情节点你就多少情节点，这就是节奏。」

## 案例（换元法谱系）
- **《狮子王》=《哈姆雷特》**（一度置换）：人物换动物、背景换非洲草原、核心故事（复仇）不变。
- **《棋士》≈《绝命毒师》**（换元 + 本地化）：中年危机主角、警察亲属、性格照抄，背景事件换本地。
- **《律政俏佳人》≈《灰姑娘》**（结构置换）：故事架构不变、换背景（现代律政）+ 人物。
- **学员二度置换**「割痔疮」→「滑雪场」甜文：蹭 12 月抖音滑雪场热点，把核心事件从痔疮手术尴尬换成滑雪场尴尬。
- **反面《小时代》**：换皮不换骨——只为炫富、没完成「豪门家族从盛到衰」的结构性置换，元素换得不对。

## 可执行清单
- 填六源表 → 选一度或二度 → 出 ≥3 套映射 → 逻辑校验；映射表：旧元素|新元素|理由。
- 短篇统一第一人称 + 线性叙事；人物按「三位一体 + 三字经」自查。

## 反模式
- 只改名字当创新；元素堆砌导致主题漂移；未声明模式的洗稿；人物违背三位一体；短篇乱用人称写多视角；一度二度混用不自知。
