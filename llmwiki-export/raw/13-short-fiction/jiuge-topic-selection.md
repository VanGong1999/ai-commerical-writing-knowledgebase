# 短篇选题：扒榜、老梗缝合、热点落地与受众定位
> 来源：九格 / 9.md（商业化短篇小说选题）
> 权威级别：P0
> 关联 Skills：topic.short_pick, topic.audience
> 关联 Agents：ShortTopicAgent

## 一句话
商业化短篇选题的核心**不是写自己喜欢的，而是写读者喜欢、市场需要、同时有自己的特色**——懂读者 + 懂市场 + 有特色。

## 底层认知
- 商业化网络小说 = 能带来收入的作品；写文艺唯美的未必是商业化。
- 写作不是 1+1=2；上课是学「老师的思路」，不是学标准答案；能迁移、发散才算入门。
- 想把写作当终身事业，建议学一点**心理学**——写作归根结底玩的是人心、人性。

## 选题技巧一：扒榜，找平台口味
- **扒榜**：去目标平台看它的榜单，摸清平台「脾气」，投其所好；写得再好投错平台也白搭。
- **按平台选榜单**：知乎严选 → 新书榜/热度榜/完结榜；起点 → 畅销短篇/潜力短篇；番茄 → 热搜榜/听书榜等。
- **只看两个东西**：核心设定 + 关键词，再扫一眼故事内核；不必看完一整本。
- **不看前 3 名，前 20 名都扫**，找重复出现的关键词（如严选榜近期常现：现实悬疑、中式志怪、女性成长），往这些方向靠，投稿成功率更高。
- **扒榜是找规律，不是抄设定**：大家都写女性成长，你就写「女主靠自己、姐妹互助」而非「被男主拯救」——差异化。
- 案例（设定迭代）：普通重生逆袭打脸已看腻；换角度写「重生回 10 年前帮妈妈避开职场 PUA、治愈原生家庭创伤」——保留「重生」这一平台喜欢的核心设定，内核换成职场霸凌/女性互助/原生家庭（临近过年热点），符合精品化去同质化。
- 案例《无暇赴死》（知乎）：多线并置、谎言与真相交织，看似悬疑老设定、内核是人性复杂，成爆款并进「最具影视价值 IP 榜」。方法论：**抓设定但不局限于设定，还要抓内核**。

## 选题技巧二：老梗新缝合，制造反差
- 老梗经过市场检验、读者接受度高（降低试错率）；原样写会被毙「同质化严重」；关键是**反差 + 逻辑自洽**。
- **当前最火复合题材组合**：规则怪谈 + 无限流；中式克苏鲁 + 民俗悬疑；轻科幻 + 仙侠（轻科幻不是硬科幻）。
- 案例：恐怖游戏 + 抑郁小女孩（抑郁小女孩在恐怖游戏里大杀四方，现实脆弱↔游戏强大）；职业 + 奇幻（时间循环快递员每天送同一封道歉信，收信人是 10 年前的自己）；饥荒卖女老梗 + 逆袭掌权（开头三句三反转）。

## 选题技巧三：趁社会热点找结合点
- 盯「能引发大众情绪共鸣、能落地现实」的热点（AI 诈骗、职场性骚扰、老人防骗、女性安全、宠物经济、中式育儿焦虑）；明星八卦/鸡毛蒜皮来得快去得快、易侵权。
- **热点 + 情绪 + 深度三者结合**；把观点「润物细无声」放进情节，不直接讲理论。
- **政审看两点**：故事情节的设定 + 结局的设定；写霸凌等题材最终要带正向结果，不能传负能量，否则政审不过。
- 案例：知乎《活在真空里》用庭审翻供撕开资本霸权、司法困境，不空洞谈「资本不好」；宠物经济 + 轻科幻（赛博猫咖猫耳少女能听懂猫语，治愈赛博精神病，代价是失去记忆）。

## 选题来源二：从生活和想象挖故事（接地气）
- 读者越来越爱**有烟火气**的故事，反感悬浮人设；短剧风向标：从霸总转向普通人，越苦越难越穷越好；奇幻/科幻也要扎根现实。
- **技巧一：日常职业 + 奇幻设定**（快递员/煎饼摊主/理发师/网约车司机/茶馆老板/外卖员 + 一点奇幻）：案例「深夜煎饼摊老太太的忘忧煎饼，每帮人忘一次痛苦自己头发白一根」。
- **技巧二：市井烟火 + 地方特色**（地方化写作、国潮）：成都宽窄巷子茶馆老板听懂老茶客暗语；米花《异妖录》融合江南水乡/四川茶馆/北京胡同 + 志怪 + 非遗。方法论：**写自己最熟悉的东西**，熟悉场景思路多、画面感易出。
- **关键习惯**：动笔前先定**大框架**——准备写几个伏笔、几个反转；构思好的反转点放进框架检验逻辑，逻辑不过就放弃。

## 选题来源三：从情绪和冲突找共鸣
- 读者看故事是为了找**情绪宣泄口**（爽/哭/笑/温暖/刺激）；**情绪比文笔更重要**（认识字、能说清「谁在哪干什么」就能学）。
- **技巧一：制造反差和反转**。最受欢迎结构：开篇三句话反转 + 中间每隔几百字一个小反转 + 结尾大反转；反转要「意料之外、情理之中」、逻辑自洽。案例：死后滞留人间 72 小时不是为见亲友而是为找真凶；叛逆少女与阿尔兹海默症奶奶互换身体。
- **技巧二：道德悖论**（两难选择，怎么选都有道理有遗憾）。悖论越多，越能引发讨论和转发。案例：许愿的代价（愿望成真付出惨痛代价）；职场性骚扰 + 道德悖论。
- **技巧三：开局暴击（黄金三秒钩子）** = 反常识 + 强冲突 + 高悬念。案例：「我亲手锯断自己的腿，防止它半夜杀人」「我埋了丈夫三次，他每次都能自己爬出来」。
- **嘴替开局**：把读者心里想的东西替他说出来。

## 选题技巧四：精准定位受众
- **选题第一步其实是定位受众**；能感动自己的故事未必能感动市场。
### 年轻读者（18–35 岁，95/00 后/Z 世代）
- 特点：好奇心强、喜新奇反套路；喜强情绪；关注 AI/虚拟世界/国潮/女性成长；碎片化、快节奏高频反转；重自我表达（社恐/职场内卷/原生家庭）。
- 三方向：① 女性成长 + 反套路（拒绝雌竞、恋爱脑，写女性互助、搞事业，结合「不结婚不生娃」热点）；② 轻科幻 + 情绪宣泄（扎根现实，科幻元素只是辅助）；③ 反套路甜宠（平等尊重、互相成长、轻松治愈，拒绝悬浮霸总）。
### 中老年读者（40 岁以上）
- 被新手忽略的潜力市场；喜现实题材、反感奇幻悬浮；重情感共鸣（亲情友情爱情怀旧）；关注养老/子女教育/夫妻/邻里/退休生活；不喜快节奏，喜烟火气、地方特色、剧情连贯、正能量。
- 市场越来越大（尤其有声书 + 中老年向短剧）；变现渠道广（中老年短剧/微电影/实体书）；**投钱意愿比年轻人强**。
- 三方向：① 亲情向 + 养老困境；② 怀旧向 + 时代回忆（年代文，参考番茄 70/60/80 后，临近年关进入热度期）；③ 现实困境 + 正能量。

## 可执行清单（选题九步）
1. 定受众（年轻/中老年，只选一边）→ 2. 按平台扒榜扫前 20 名记关键词 → 3. 从四技巧两来源选方向做「热点/老梗 + 擅长领域 + 情绪点」加法 → 4. 老梗为底加不搭边元素、验逻辑 → 5. 动笔前定伏笔/反转数量与位置 → 6. 写导语（约 200 字，五觉法拉读者、拎爽点）→ 7. 正文 11–13 个故事情节，冲突往高写、爽点递进 → 8. 手搓改标点去 AI 味 → 9. 静置自检后按平台口味投稿。

## 反模式
- 把「自己喜欢的」当商业化选题；只蹭热点不挖情绪深度；扒榜变抄设定。
- 乱炖但逻辑不自洽；故事里直接讲理论、带个人看法（易引争议、政审风险）。
- 为爽而爽/为虐而虐的悬浮；受众两边讨好；伏笔反转边写边设。
