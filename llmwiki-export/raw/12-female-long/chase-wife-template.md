# 追妻火葬场模板
> 来源：九格 / 8.md、流程文；手册
> 权威级别：P0
> 关联 Skills：chase-wife, manju.core_hook
> 关联 Agents：CoreHookAgent

## 一句话
追妻是强情绪女频/漫剧高热模板：**虐→毁→追→合**（或五部曲：决裂→转折→觉醒→追妻→结局），伤害→悔→追→反复拉扯，爆点前置，反派无好下场。

## 情绪链条（核心梗模板）
- 被伤害方：受挫 → 期待 → 委屈 → 积累失望 → 决裂。
- 伤害方：忽视/过错 → 后知后觉 → 幡然醒悟 → 悔恨 → 付出。
- 模板结构「虐→毁→追→合」：虐一般**虐三轮**（一而再、再而三、三而竭）；毁是通过什么方式毁；追也追三轮；合（HE/BE）——爽文技巧**反派一定没有好下场**（含白月光）。

## 追妻火葬场五部曲结构（8.md）
| 阶段 | 内容 | 关键点 |
|---|---|---|
| 1. 决裂期 | 女主重生主动提和离，男主冷漠应对 | 女主首要目标是**远离男主** |
| 2. 转折期 | 女主家族遇危机，靠前世记忆化解，男主开始注意到变化 | 写女主遇什么困难、如何解决 |
| 3. 男主觉醒期 | 男主发现前世误解女主/看到女主变强大，开始后悔 | 男主后悔 = 追妻的开始 |
| 4. 追妻期 | 男主主动示好均被女主拒绝 | **爽点**：情绪逐步叠加，读者期待女主如何对待男主 |
| 5. 结局 | 女主达成终极目标；男主彻底悔悟但求而不得（或复婚/不复婚/开放结局） | 结局由作者风格与擅长方向决定 |
- 核心事件**逐步添加、强度递进、环环相扣**（像俄罗斯套娃）；不要一章全抛；女主不能过早原谅，否则后续无法推进。
- 核心事件是「多个事件的组合」，每个事件内又含多个情节点（如「暴雨抢药材」三情节点：遇危机男主帮忙→男主暴露弱点女主动摇但保持警惕→男主表达悔意女主明确拒绝强化决裂）。

## 可执行清单
- 写出伤害事件、悔点、追的行动、见证打脸点；按五部曲逐阶段标注「女主目标/男主状态/情绪强度」。
- 追妻情绪拉扯用「决裂立场反复强化」维持张力（参考七猫离婚题材小说，写 70 多万字还没离成，靠不同事件推动离婚目标）。

## 反模式
- 无悔无追的空壳虐；男主渣到底无成长还不火葬；女主过早原谅（后续无法推进）；核心事件一章全抛。

## 与其他课差异（若有）
- 无显著冲突；按权威源原则引用。
