# 故事=意外（北大博士）
> 来源：北大博士教你故事变现 / 第 01~10 课 + 全课程核心精华（讲师刘六六）
> 权威级别：P0
> 关联 Skills：struct.*
> 关联 Agents：WritingOrchestrator

## 一句话
故事的本质是「意外」：稳定被不可抵抗的力量打破 → 挣扎 → 爬出；写故事 = 虐主（三角冲突 + 怨憎会 + 怕什么来什么）+ 撩观众（认知差异 + 偏离预期）。

## 故事的本质：意外 + 三幕式
- **故事 = 意外**：一个本来稳定的人，被一股不可抵抗的力量打破平静（第一扇门），被迫改变、挣扎、经历困境，最终爬出来（第二扇门）。
- **三幕式**：开端（掉进去）→ 中间（挣扎）→ 结局（爬出来）。所有故事都是三幕式。
- 没有意外的人生 = 没有故事的人生。
- 讲故事 ≠ 文学创作（后者有天才，前者有规律）。

### LOCK 系统
Lead（主角）→ Objective（目标）→ Confrontation（冲突）→ KO（一击致命结尾）。

### 36 种情节模式
90% 的出版 / 传播故事都在其中，最受欢迎的 6 种：不幸、解谜、为主义牺牲、为骨肉牺牲、恋爱的罪恶、恋爱被阻隔（课程口径）。

## 心法一：虐主（怎么对待主人公）
> 把主人公当成你今生最大的仇人，尽你所能虐待他。

- **三角冲突（邪恶的选择）**：价值要正面且大 → 替代方案在价值反面 → 代价拉到最大（最好是生命）。
- **怨憎会**：安排一个目标相反、阻挠成长的反派，并与主角**捆绑**在一起。
- **怕什么来什么**：他怕什么，就给他什么，让他时刻不得安生。

## 心法二：撩观众（怎么对待读者）
> 把观众当情郎，你的故事是姑娘。

- **认知差异**：观众认知与真相永远不同步，要**引导**它，不要急着消除它。
- **偏离预期**：先建立预期，再偏离它，情绪就来了。
- **结论让观众自己得出**（写坏人要「反着写」，如茅盾《子夜》）。
- 适用所有类型：喜剧、悲剧、恐怖、悬疑的底层都是「认知差异 + 偏离预期」。

## 完整写作流程
```
第一步 写「故事线」（一句话）      ← 至少一个意外 + 故事空间
第二步 填「节拍表」（15 节拍）     ← 中间点 = 假结局，反中点相反，绝症时间
第三步 设计「场景」（40~60 个）    ← 每个场景：一个冲突 + 转折变化
第四步 写人物 / 情节 / 对话        ← 三法宝 / 悬疑 8 步 / 对白两法
```

### 故事线（一句话的写法）
- 要素①：**意外** = 一个人本来可以做这件事，却做了另一件事。
- 要素②：**故事空间** = 这句话能膨胀出整个故事。
- 结构三要素：材料、顺序、意图。

### 节拍表（三个最关键节点）
| 节点 | 位置 | 含义 |
|---|---|---|
| **中间点** | 第 55 页（110 页剧本） | 「一无所有」的假结局 |
| **反中点** | 中间点之后 | 与中间点完全相反 |
| **绝症时间** | 反中点 → 结局之间 | 对人物价值的大考验 |

### 场景（血肉）
- 一个场景 = 一个微故事 = **一个冲突 + 一种转折变化**。
- 功能 = **情绪改变 + 冲突推进目标**；边界 = **一个场景一个冲突**。
- 三种逻辑：生活逻辑、情感逻辑、命运逻辑。
- 场景密度决定节奏（热播剧一集要足够多场景）；序列要有递进。

### 人物三法宝
1. **不写典型人物**（把想到的形容词画圈，反着替换）。
2. **表里不一**（内心与表象相反）。
3. **与缺点斗争**（直到克服或被反噬）。

### 情节：悬疑 8 步
> 情节 = 因果关系；毁掉故事 = 「老实人叙述」（按时间顺序、毫无遗漏）。
目标 → 提高筹码 → 增加危险 → 推向危险 → 利用未知 → 戏剧反讽 → 秘密 → 变身。

### 对话：对白两法
> 对白就是行动；好对白满足求知欲 + 情感共鸣。
1. **为角色建语料库**（每人说话方式不同）。
2. **化身角色**（站他角度想动机再开口）。
- 叙事驱动型：牢记「然后又怎样？」；情感共鸣型：让观众把人生欲望移植到人物欲望。

## 可执行清单
- 一句话故事线自检：含「意外」吗？能膨胀出「故事空间」吗？
- 节拍表检查三节点：中间点（假结局）→ 反中点（相反）→ 绝症时间（大考验）。
- 场景密度检查：每个场景是否「一个冲突 + 一种转折变化」？
- 人物三法宝自查：是否反着写？是否表里不一？是否与缺点斗争？
- 情节用悬疑 8 步重排，避免「老实人叙述」。

## 反模式
- 无意外的流水账人生（没有第一扇门 / 第二扇门）。
- 急着消除认知差（观众一猜中就没情绪了）。
- 把场景写成「没有转折的过场」。
- 写典型人物、内心与表象一致、缺点不斗争。
- 情节按时间顺序平铺（老实人叙述）。
