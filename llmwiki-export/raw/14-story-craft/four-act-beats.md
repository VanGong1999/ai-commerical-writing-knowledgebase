# 四幕式节拍表
> 来源：编剧孵化营（10 三幕式、11–12 故事节拍表 1–2）
> 权威级别：P0
> 关联 Skills：struct.beat20, struct.midpoint
> 关联 Agents：WritingOrchestrator

## 一句话
三幕式（建制—对抗—解决，约 1:2:1）可扩为四幕式（建制—推进—转折—解决，对应起承转合）；**故事中点**落在中间（伪胜/伪败）；**金牌道具**开场埋下、第四幕重新解读，闭环解局。

## 剧本四大硬性要求（课内口径，进入「写剧本」阶段强制执行）
1. **可视听化**：每场戏能被看见/听见；「拿事儿说话」，不写「渐渐意识到」「心头一紧」（改「眉头一紧」）。
2. **按放映顺序写**：不再按「身份→境遇→目标→行动」的讲故事顺序。
3. **禁闪回**（开场画面可回忆，进入正文严禁）。
4. **练习阶段禁旁白/内心独白**（开头可少量交代背景）。

> 禁闪回/旁白是**数据驱动**的商业判断（课程口径）：出现闪回/旁白/独白，完播率、拉新率往下掉，分账缩水；旁白是「视听盘子装满后」才动用的工具。

## 三幕式 → 四幕式
- 三幕式：建制（提出问题）— 对抗（对抗问题）— 解决（解决问题），时长约 **1:2:1**。
- 四幕式：把「对抗」拆成「推进＋转折」，每份约半小时，暗合东方**起承转合**。
- 拆出「转折」催生现代商业片关键概念——**故事中点**。

## 四幕式节拍表（填空模板）
| 幕 | 节拍 |
|---|---|
| 第一幕·建制 | 开场画面 → 世界（规则/人/状态，用事件表达）→ 人物（技能救猫咪、缺失龟壳、现状、关系）→ 激励事件（第一次意外）→ 争执（拒绝召唤）→ 目标 → 主题（台词点出，5 分钟内） |
| 第二幕·推进 | 仪式感（征途画面）→ 伙伴/导师/关键道具 → B 故事（成长开端）→ 游戏时光（卸力）→ 试炼 → 接近目标对抗 → 故事中点（伪胜/伪败） |
| 第三幕·转折 | 否决中点 → 调整方向/方法/对手（认清真相）→ 对抗升级（对手逼近）→ 大意外（二号意外 PLUS）→ 灵魂黑夜/死亡气息 |
| 第四幕·解决 | 仪式感 → 疗伤 → 大成长蜕变（母胎重生）→ 解决悖论 → 决战（主角亲手）→ 目标达成 → 结束画面呼应（视而不同） |

### 关键节点详解
- **激励事件**：第一幕核心，即「第一次意外」，分大激励（爹死了/船炸了）与小激励（要不要去印度卖药）；本质是意外，激发主角走出舒适区。
- **争执（拒绝召唤）**：激励后主角至少一个回合拒绝（程勇一开始拒绝去印度）。
- **主题点题**：必须用**台词**明说，放第一幕前半段（教材甚至说 5 分钟内）。
- **游戏时光（卸力）**：第一幕大量信息＋意外刺激后，观众认知疲劳，用轻快内容（躲雨/摘苹果/BGM）让观众进入「恍惚状态」，完成认知层→情感层切换；别名「拍电影海报」。
- **故事中点**：第二幕结尾，伪胜利/伪失败；第二幕是胜利→第三幕揭穿其虚假；是失败→第三幕发现还有别的路。
- **灵魂黑夜（一无所有时刻）**：第三幕结尾让主角失败，伴随死亡气息。
- **解决悖论三法**：**重新解读道具**（加勒比的金牌）/ **孤注一掷** / **自我牺牲**。
- **金牌道具闭环**：开场埋下 → 第二幕自然存在 → 第四幕重新解读成解局关键。
- **结束画面呼应开场画面**（视而不同）：回到原点，但人已不是当初的少年。

## 案例要点
- **加勒比海盗**：孤儿主角、龟壳（铁匠房怕水）、缺失（自我认知）、激励（女主被抓）、导师（杰克船长）、关键道具（金牌）——「金牌开场在脖子上、第四幕重新解读」的完整闭环。
- **摇滚校园**：第一幕埋下「假身份」缺陷，在第三幕灵魂黑夜爆炸；「开场在舞台、结束在舞台」视而不同。
- **印度妈妈找女儿**：伪胜利三种处理——① 被识破跑不掉；② 女儿已死（转而报仇）；③ 女儿斯德哥尔摩（转而调整目标）；「决战」用智谋实现而非打架。

## 可执行清单
1. 写前十个故事严格当「填空题」套四幕式：按每幕节拍逐项填空。
2. 关键概念中性理解：决战可以是比赛、游戏时光可以是「符合观众预期」的非欢乐内容。
3. 检查：中点是否有伪胜/伪败？灵魂黑夜是否带死亡气息？解决悖论是否用「重新解读道具/孤注一掷/自我牺牲」？结束画面是否呼应开场？
4. 用四幕表填节拍，再映射到短剧集/章（对照 `06-structure/fifteen-vs-beat20.md`）。

## 反模式
- 中点后仍慢热、无升级；第三幕不否决中点直接顺下去。
- 解决靠对手突然变蠢；旁白/闪回推进剧情（盘子没装满就找锅）。
- 结束画面不呼应开场，漏掉「回到原点」的闭环。

## 与其他课差异
- 电影时长节拍与短剧 `beat20` **同构不同粒度**：四幕式是电影级节拍，beat20 是短剧付费体量上的加密，中点物理位置相同（约一半）。
- 中点/至暗时刻的单独展开见 `06-structure/midpoint-dark-night.md`；剧本硬性要求（可视听化/禁闪回旁白）与短剧、小说创作边界相关。
