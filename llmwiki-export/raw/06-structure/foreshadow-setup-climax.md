# 伏笔、铺垫与高潮
> 来源：小说零基础写作班 / 32–33；编剧孵化营小伏笔
> 权威级别：P0
> 关联 Skills：struct.*
> 关联 Agents：WritingOrchestrator

## 一句话
伏笔是长线可忽略闲笔、后文照应才恍然；铺垫是短线显性造势、不可删；高潮＝欲扬先抑后爆发（揭秘/光环/反转），必须有不可逆反馈。

## 伏笔 vs 铺垫（零基础 32）
| | 伏笔 | 铺垫 |
|--|------|------|
| 距离 | 长线 | 短线 |
| 形态 | 可忽略闲笔 | 显性不可删 |
| 体验 | 后文恍然 | 当下造势 |
- 概念别死抠，用活即可；伏笔要留回收表，铺垫要服务当下造势。

## 高潮 SOP（零基础 33）
```text
欲扬先抑（设低谷）→ 爆发三模式：揭秘 / 光环 / 反转
→ 不可逆反馈（人设/关系/格局回不去）
```
- 可有大高潮与小高潮；高潮≠打得凶。
- 爆发三模式可单选或组合；反转需前文有伏笔/铺垫支撑。

## 金牌道具（编剧孵化营）
- 开场埋、后解读：一件道具在开篇出现（看似普通），后文揭其关键作用——伏笔的「物件化」用法。

## 可执行清单
- 列出长线伏笔回收表（伏笔→埋点章→回收章→效果）。
- 高潮前检查：低谷是否够低？爆发属哪种模式？反馈是否不可逆？

## 反模式
- 伏笔遗忘不回收；铺垫与伏笔概念死抠。
- 高潮无不可逆变化（打完世界不变）。
- 反转无前文支撑，纯靠「突然」硬转。

## 与其他课差异（若有）
- 本文为**零基础**通用结构口径（伏笔/铺垫/高潮三概念 + 不可逆反馈），叠加编剧孵化营「金牌道具」物件化补充。狂更猫无独立伏笔课，其「读者预知/信息差」与本文铺垫逻辑相通（见 `07-emotion-cool` 与 `opening-attract.md`）。
