# 漫剧十八爽点 + 卡点三类（手册干货切片）

> 来源：AI漫剧实操手册（提示词）第六节  
> 领域常量：`MANJU_COOL18_MODELS` / `MANJU_KARTIAN_TYPES`  
> ≠ L6 Maslow+cool12 / CoolFaceSlap

## 一句话

集纲每集点名 1–2 个十八模型 + 一个卡点类型；人工「能不能用」后再写正文。

## 五维（模型名）

- 力量与征服：绝对惩戒 / 扮猪吃虎 / 装逼打脸 / 掠夺与暴富  
- 成长与逆袭：绝境反杀 / 永不屈服 / 力挽狂澜 / 持之以恒  
- 智慧与谋略：智商碾压 / 幕后黑手 / 慧眼识珠 / 偷听秘闻  
- 情感与关系：报仇雪恨 / 被偏爱 / 英雄救美  
- 机遇与命运：寻宝奇遇 / 意外之喜 / 俄罗斯套娃  

## 卡点三类

1. 悬念勾子（然后呢？）：危机降临 / 未解之谜 / 惊人宣言 / 关键转折  
2. 爽点爆点（太牛了！）：实力打脸 / 认知反差 / 势力反应 / 收获时刻  
3. 情感钩：守护宣言 / 情感联结  

## 反模式

- 与 cool12 混为一谈
