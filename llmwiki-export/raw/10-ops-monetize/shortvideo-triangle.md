# 短视频三角定位与需求三级
> 来源：查理老师的短视频商业训练营 / 全课程核心精华 + 全课程知识体系（第 2~6 课）
> 权威级别：P0
> 关联 Skills：biz.product_align
> 关联 Agents：WritingOrchestrator

## 一句话
先定「变现方式」（至少两个）当目标，再用「三角定位」选赛道：自身局部优势 → 用户需求 → 平台变现，顺序不能反；用户需求分激素 / 人性 / 价值三级，越往前受众越广。

## 三角定位法（选题核心方法）
做一个账号，从三个角度定位，**顺序不能反**：

```
① 自身（有什么优势）→ ② 用户（要什么）→ ③ 平台（怎么变现）
```

- **底层主张**：先想「钱从哪来」（变现方式），再选赛道。变现是后面所有课的「锚」。
- 先定变现方式（至少两个），选题才有依据；没有变现目标就做账号等于先选赛道再找钱（反模式）。

## 自身角度：找「局部优势」
- **核心信念**：互联网只相信长板，不相信全能。
- **优势标准**：**百里挑一即可**，跟普通人比，不是跟赛道王者比（跟王者比只会放弃）。
- **找法**：回忆「被外人夸过 5 次以上」的事——别人反复夸的，往往是你没意识到的优势。

### 九类优势清单
| # | 类别 | 典型例子 |
|---|---|---|
| 1 | 产品 / 服务 | 养蜜蜂、修车、淄博烧烤 |
| 2 | 身份 / 职业 | 警察、消防员、全职妈妈、某行业从业者 |
| 3 | 资源（先天） | 草原、家乡、民族、赶海、金矿 |
| 4 | 技能 / 知识 | 弹琴、开车、钓鱼、知识分享 |
| 5 | 天赋 | 好看、高、腿长 |
| 6 | 爱好 | 爱梅西（集锦号）、爱八卦 |
| 7 | 藏品 / 财富 | 收藏、炫富 |
| 8 | 借力 | 家人、孩子、宠物、附近资源 |
| 9 | 缺陷 | 强迫症整理号、脑瘫 + 写诗 |

### 六条运用结论
1. 优势多时，优先选**稀缺度最高**的。
2. **2~3 个优势叠加**使用（单一优势支点太脆）。
3. 适当利用**反差**（丁真：资源 + 天赋 + 反差；野牦牛：牧民 + 美式英语）。
4. **多听别人怎么说**，别自恋（自己以为的优势未必是市场优势）。
5. 展现优势 = 最好的人设 / IP。
6. 人人都要叠加一项「**创作能力**」（会拍 / 会写 / 会剪）。

## 用户角度：需求三级框架
> 核心认知：不是给用户贴画像分类，而是**分析需求**（互联网思维）。

```
一级（激素级 / 动物级）：性（繁殖）、暴力（征服）、快乐
二级（人性级）：优越感、归属感、认同（共鸣）、情感治愈、秩序（逻辑）
三级（价值）：实用价值、效率价值（时间价值）、欣赏价值
```

### 关键点拆解
- **暴力 = 征服**，不单是打架——棍子 / 枪 / 车都是能力延伸，钱是最暴力的，版图扩张也算。
- **优越感排第一**：你姿态放低，让用户显得聪明（傻号、脱口秀、东北喜剧）。
- **归属感 = 拉踩**：国家 / 地域 / 性别 / 职业；咸豆花 vs 甜豆花就是典型拉踩。
- **秩序**：修牛蹄子、游戏、麻将、养成 / 收养报恩（无序 → 有序）。
- **价值是最后才考虑的**（别优先做知识号）。

### 三条需求结论
1. **越往前受众越广泛**（数量级差距：头部知识号 vs 颜值主播）。
2. **爽点与价值叠加使用**（一个支点不安全、不持久）。
3. **选定后不要变**（用户有标签画像，锁定同一批用户）。

## 关键案例库（跨课复用）
| 案例 | 知识点 |
|---|---|
| 牛肉坑位费 5 万卖 4000 → 牵牛卖爆 | 全品类头部网红带单品无优势 |
| 网吧大神、红绿灯的黄 | 打赏 = 存在感 / 上帝感 |
| 沙胆英（木浆海绵 75 万） | 短视频带货存留久（课程口径） |
| 淄博烧烤 | 明确产品 + 先做先放大 |
| 丁真、野牦牛（牧民 + 美式英语） | 资源 + 天赋 + 反差 |
| 强迫症整理号 | 缺陷 = 流量密码 |
| 咸豆花 / 甜豆花 | 归属感（拉踩） |
| 修牛蹄子、麻将、收养狮子 | 秩序（无序 → 有序） |
| 皮尤（汽车号 → 时尚达人） | 转型成功 = 用户需求没变 |

## 可执行清单
- 先写下「变现方式 ≥ 2 个」，再开始选题。
- 用「被外人夸过 5 次以上」法列出自己的优势，勾 2~3 个稀缺度高的叠加。
- 用三级需求框架定位：主要满足哪一层？爽点 + 价值是否叠加？
- 输出一句话定位：「基于什么优势，给什么用户提供什么爽点 / 价值，靠什么变现」。
- 验证顺序：自身 → 用户 → 平台，确认没有跳步或反序。

## 反模式
- 先选赛道再找变现（顺序反了）。
- 跟赛道王者比，导致自我否定、直接放弃。
- 只押一个支点（单一优势、单一爽点），不叠加。
- 优先做纯知识号（价值层级靠后，受众窄）。
- 频繁换人设 / 换需求（用户画像锁不住）。
