# 吸引力开篇：冲突·悬念·设定
> 来源：小说零基础写作班 / 25–29、48；狂更猫 / 04、27、46
> 权威级别：P0
> 关联 Skills：hook.*, struct.*
> 关联 Agents：CoreHookAgent

## 一句话
开篇唯一标准是「足够有吸引力」，不是「必须三章小高潮」；三条路——冲突（一个乱字+两个关口）、悬念（四类贯穿全书）、设定（背景或人物切入口）——可叠加使用。

## 开篇三法
| 法 | 核心公式 | 关键动作 |
|----|----------|----------|
| 冲突 | 一个乱字 + 两个关口 | 乱＝失衡切入；关口逐级加压；给主角「不行动就死/崩」的理由 |
| 悬念 | 四类：核心/超级/场景/段落 | 须贯穿全书，不止开篇；章末留钩子 |
| 设定 | 背景（世界观/金手指/特殊经历）+ 人物（特殊职业/魅力/热点） | 人设服务情节、融入故事、CP 互补，忌冷门 |

- **冲突三标准**：微创新、可共情、解法有反转（区别于「随便找麻烦再解决」）。
- **开篇速查链**：问读者想看什么 → 选路 → 冲突套「乱+关口」/ 设定亮世界观或金手指或魅力热点 → 书名亮核心 → 简介亮冲突悬念 → 前三章兑现吸引力 → 章末留瞬间悬念。

## 高阶切入三路（零基础 48）
1. **矛盾冲突式**：开篇把主角放进尖锐事件施压，读者期待「如何解决」。例：《人渣反派自救系统》穿成反派要抱男主大腿 + 系统禁止违背人设；《全球高武》种族矛盾 + 金手指需财富值 vs 钱不够。
2. **绝境式**：开篇即绝境，主角应对。例：《大奉打更人》穿越即监牢+流放倒计时；《全球高考》夺命考题。
3. **悬念式**：主角引发多疑点追答案。例：《法医狂妃》女扮男装+萌娃破案；《我有一座冒险屋》镜中游戏层层规则。

**压迫技巧（贯穿三路）**：主线任务问两句——「完不成怎样？完成怎样？」，后果须与主角强相关（自己/爱人/亲人死）。长期热销多与生死挂钩。

## 穿越 / 重生 / 土著设定（零基础 48）
- 穿越前**少写**；死因/穿越方式**一句话**；要写前情须是有效信息且后文起作用。
- 穿书先知＝金手指也要有压迫（系统卡死黑化节点），否则脱离原著＝普通穿越。
- 原主 vs 穿越者必须**反差**（木讷残忍 vs 欢脱善良），无反差无改编意义。

## 狂更猫：前五章基调 = 展示主角优势
**万能稳妥开头五步（男频/通用，04）**：
1. 穿越醒来 + 世界观 + 危机/催系统 + 出系统（说明能干嘛）+ **章末读者预知**。
2. 铺垫视角（震惊对象，约 300 字即回主角）→ 定小目标、再强调优势。
3. 增加视角（直播最简单）。
4. 欲扬先抑 → 装逼打脸（必须加对比）。
5. 爽点扩散 + 收获盘点 + **下一目标仍服务大目标**。

**黄金第一章五信息点（约 2000 字，46）**：世界背景 / 穿越重生 / 当下事件或危机 / 系统优势 + 思考定目标（思考不可省）/ 进入世界事件。

**女频第一章五要素（09/40/45）**：女主是谁、在怎样的世界 / 金手指 / 面临现状（人物宜少）/ 思考与行动（主线方向）/ 有效突发事件（能接第二章，非空钩子）。

## 可执行清单
- 开篇自检：是否有微创新、可共情、解法有反转？
- 章末是否留下「读者预知」（优势将如何作用）？
- 前五章是否把主角优势展示清楚？系统/金手指是否说明能干嘛？
- 穿越文：前情是否已压到「一句话」、有效信息才留？

## 反模式
- 开篇说明书式世界观、名词轰炸不进冲突。
- 悬念只在第一段，后文不贯穿。
- 为后文憋着前面不敢爽；主角自己找上门掉逼格。
- 信息后置（第一章剧情完、第二章才补设定）。

## 与其他课差异（若有）
- 双源合并：**零基础**给出「冲突/悬念/设定」三法 + 高阶切入三路与穿越注意点（偏结构拆解）；**狂更猫**给出「前五章展示优势」的开头五步与第一章五信息点（偏可执行模板）。二者互补：三法回答「为什么被引进去」，五步/五信息点回答「按什么顺序写出来」。
