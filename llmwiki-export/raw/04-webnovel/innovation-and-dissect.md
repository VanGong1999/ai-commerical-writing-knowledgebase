# 微创新、反套路与拆爆款
> 来源：小说零基础写作班 / 07、40–41；狂更猫拆书 / 14、23、31
> 权威级别：P1
> 关联 Skills：dissect.*, topic.*
> 关联 Agents：DissectAgent, TropeMineAgent

## 一句话
新手主做微创新/陌生化，勿神话开创类型；拆书找「赚钱机制」落表，禁止只贴「有悬念」标签或扒大纲换皮。

## 微创新 / 陌生化三法（零基础 40–41）
| 法 | 操作 |
|----|------|
| 叙述结构微调 | 罗生门/环状/倒置等局部使用 |
| 反套路 | 骗过读者固化预期 |
| 穷举组合 | 结构×情节×人设×背景×冲突五元素，或变换关键元素 |

- 区分**刻板形象 vs 典型形象**；百分百开类型可遇不可求，微创新即可。
- 创造力＝把看似无关之物连起来。

## 拆爆款四件套（零基础 07）
心态：找「赚钱机制」，不是先骂。按原文顺序读开篇，落四表：
| 表 | 内容 |
|----|------|
| 梗概 | 发生了什么（框架感） |
| 卖点 | 为何吸引人 |
| 感情线 | CP 推进节点 |
| 节奏 | 章/段信息与情绪起伏 |
- 自问：它如何为平台赚钱？提炼**可迁移机制**，禁止只贴「有悬念」标签。

## 狂更猫拆书 SOP（14/23/31）
- **女频四问**：背景 / 女主人设 / 金手指 / 主线本质。
- **章节拆七项**：梗概 / 节奏类型（铺垫·反应·爽点·盘点）/ 五要素 / 人物 / 转场 / 钩子 / 自己觉得爽的地方。
- 拆完对标「章功能」写自己情节，不抄事件。

## 可执行清单
- 拆完一本书写出「可迁移机制」一句话（如「用系统强制不能违背人设制造冲突」）。
- 微创新前自问：是否换了关键元素（结构/情节/人设/背景/冲突）之一？

## 反模式
- 只贴「有悬念」标签不落表；逐课复述案例剧情当知识库。
- 为创新而创新穷举到不可写；神话开类型。
- 扒热销大纲换皮；只换背景名词不换人物动机。
