# 草纲到细纲的层级
> 来源：小说零基础写作班 / 10–14、17
> 权威级别：P0
> 关联 Skills：struct.*
> 关联 Agents：WritingOrchestrator

## 一句话
草纲→总纲→大纲→细纲→正文，五级把「核心梗」长成「可写结构」；总纲想事、大纲讲结构、细纲保日更，思考路径比写本身更重要。

## 四级纲角色与分工
```text
草纲（骨架）→ 总纲（脏腑）→ 大纲（经脉/故事线）→ 细纲（场景路径）→ 正文（血肉）
```
| 级 | 干什么 | 对应认知 |
|----|--------|----------|
| 草纲 | 一句话到几行的故事骨架 | 核心梗 |
| 总纲 | 想「事」：主线、人设、背景、分阶段剧情 | 脏腑（全局） |
| 大纲 | 讲「结构」：叙述顺序排兵、九节点 | 经脉 |
| 细纲 | 讲「场景」：每章写什么、动因与前因 | 日更保障 |

不必每级都写到极致，但思考层级要清晰；**路径比对写更重要**。

## 总纲四步（11–12）
1. **一句话主线**。
2. **独特性故事纲要**（草纲级扩展）。
3. **人设表 + 背景设定**（名词/地图/规则）。
4. **分阶段剧情纲要**：地图法 / 等级法 / 进度法（可混用）。
   + 言情另留感情大框架；开局关系优先**久别重逢**（降低硬捏化学反应）。
   - 感情四步框架（课内）：初相识 → 相处矛盾 → 解决 → 在一起。

## 大纲：九节点 + 冲突万能公式（13）
- 九节点可作全书大结构，也可嵌进小情节；可只用 3–5 个。
- 推不动节点 → **冲突万能公式**（加压/对抗/选择）；「冲突不会想 = 阅读量还不够」。

## 细纲四法拉长（14）
| 方法 | 作用 |
|------|------|
| 剧情拆解 | 一句话事件拆成可写步骤 |
| 剧情推导（逆推） | 从结果倒推必要前因 |
| 戏剧冲突 | 加压、对抗、选择 |
| 产生对比 | 人设/处境/前后对比出张力 |

- **日码万字以上靠细纲**；细纲不绑架章节字数。
- 开篇忌只陈述故事、不交代动因（细纲补前因与渴望）。

## 开书全流程（17）
```text
灵感/核心梗 → 微创新或反套路调整 → 设定整理（人设+背景）
→ 草纲 → 总纲 → 大纲 → 细纲 → 正文
→ 卡文则回对应层级（大情节点回大纲；走场回细纲/代入）
```

## 可执行清单
- 开书前确认：是否有可执行细纲支撑日更？
- 总纲四步是否齐全？言情是否留了感情大框架？
- 卡文先判断层级（大情节/衔接/描写/走场）再回对应层，不空改正文。

## 反模式
- 无纲硬写又乱改（至少想清四级路径）。
- 大纲过复杂导致写不下去（0 基础课误区：纲是工具不是负担）。
- 无纲开长篇；细纲写成「只陈述不交代动因」。

## 与其他课差异（若有）
- 本文为**零基础四级纲体系**（偏工程化、分层思考）。狂更猫不强调四级纲，改用「三万字倒推/循环 + 不卡文神器」直接落地（见 `gold-finger-and-loop.md`、`title-blurb-stuck.md`），二者可互补：四级纲管全局，循环/十条管单段推进。
- 红娘子千字大纲四块（故事/人物/冲突/立意）可作对外版大纲，本文件不重复展开。
