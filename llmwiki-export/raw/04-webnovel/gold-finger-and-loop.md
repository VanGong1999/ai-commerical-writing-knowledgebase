# 金手指与循环写法
> 来源：小说零基础写作班 / 39；狂更猫 / 20、44、51
> 权威级别：P0
> 关联 Skills：struct.*
> 关联 Agents：WritingOrchestrator

## 一句话
金手指＝把不合理「合理化」的造梦装置：少而可延伸、弱开有成长；循环＝用固定金手指反复解决问题的思路（不是「报复一个人一个循环」）。

## 金手指（零基础 39）
- **本质**：给爽点一个逻辑外挂，让「不合理」变得自洽。
- **三共性底线**：能说清能干嘛/不能干嘛；少；可延伸；弱开有成长空间；服务核心爽点且逻辑自洽。
- **四方面想设**：与主题/背景碰撞出矛盾（禁区、代价、冷却、暴露风险）——摩擦即剧情，不是设定百科。
- **雷区**：又多又满级开局；万能解一切冲突；规则无限叠。

## 循环三要素（狂更猫 51）
```text
主角目标 + 金手指 + 核心（爽点来源）
```
- **主线 ≠ 核心**：升级是「来源」，不是爽点本身；核心才是读者点进来的理由。
- 循环＝用**固定**金手指、固定方式反复解决问题的写作思路；循环负责「思路从哪来」，搭台子负责「这段怎么写好看」。

## 一个循环怎么写（51）
```text
1 拉出主角目标 → 2 给目标找逻辑 → 3 设置阻碍 → 4 围绕核心制造有关系的对比爽点
→ 5 获得/展示奖励（展示要快）→ 6 用新阻碍/误会/期待续到目标完成
→ 7 结算 → 新目标 → 下一循环
```

## 三万字倒推（狂更猫 03，量词非死板字数）
```text
判断（能否循环/有无对标热度/难度适合）→ 定第 1 个 3 万字终点（震惊/阶段性变强）
→ 倒推约 15 章章纲（章约 2000 字）→ 中间章只推进不跑题 → 第 2 循环＝第 1 循环加强版
```

## 心理推进口诀（主视角，狂更猫 20）
所见 → 五感 → 思考 → 金手指问题 → 再行动。

## 可执行清单
- 写「金手指规则卡」：一句话能力 / 可做 / 不可做 / 代价 / 成长阶。
- 每个循环填「循环卡」：目标 / 金手指用法 / 核心爽点来源 / 压抑场 / 爆发决策 / 打脸对比 / 奖励展示 / 新目标。
- 三万字倒推先定终点震惊点再倒推章纲。

## 反模式
- 金手指规则膨胀失控、多系统互不统属。
- 升级当爽点本身而无对比展示；奖励展示拖沓。
- 把「报复成功一个人」当循环终点；金手指替代角色思考。
