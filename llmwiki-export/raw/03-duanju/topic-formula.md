# 短剧选题三公式
> 来源：查理短剧课 / 2.1、5.1、6.8；全课程核心精华
> 权威级别：P0
> 关联 Skills：topic.formula, topic.want_how, topic.account_tier
> 关联 Agents：CoreHookAgent

## 一句话
选题 = 爽点 + 共鸣(YY) + 故事壳（基础版）；爽剧极简 = 想怎样 + 通过啥（6.8）；投稿按号级选策略：满级号设「有创意的明确目标」，小号优先「开挂三型」。

## 先忘掉「赛道分类」
- 市面赛道（都市战王、乡村神医、赘婿、离婚、霸总、甜宠、古言、修仙……）多从新媒体小说/YY 小说直接搬来，初期借用尚可，但短剧与小说本质不同，未来分类必然分化。
- 爆款常「赛道串烧」：先赘婿 → 迅速离婚 → 原是都市战王复仇 → 同时还能治病是神医。硬套单一赛道会失效。
- 正确做法：先搞清选题逻辑，再谈选哪条赛道。**题材 = 爽点，不是壳子**——别问「能不能写校园/电竞/末日」，要问「爽点是什么、有几个、贯彻了没有」。

## 选题逻辑链（从产品到公式）
```
产品三性（解压·代入·粘度）
  → 故事四元素（世界观·人物·事件·主题/获得感）→ 短剧压缩前三项，突出爽感
  → 精彩三指标（对抗·变化·共情）→ 短剧最重共情
  → 选题 = 爽点 + 共鸣
  → 装进故事壳
```

### 故事四元素在短剧的处理
| 元素 | 定义要点 | 短剧处理 |
|---|---|---|
| 世界观 | 何时何地、世界运行规律 | 往往不展开 |
| 人物 | 必须有角色 | 人设不复杂，常无传统成长弧 |
| 事件 | 发生了什么 | 保留 |
| 主题 | **观众的获得感**（不是作者想表达什么） | 侧重其中的**爽感** |

### 精彩三指标（体育赛事类比）
| 指标 | 含义 | 类比 |
|---|---|---|
| 对抗 | 主角势力 vs 对手势力 | 拳击：对抗越激烈越赚钱 |
| 变化 | 局势起伏 | 足球比篮球火：变化多、难知结果 |
| 共情 | 产生共通情感、「与我有关」 | 买了足彩更投入 |

短剧四元素里最关心「爽感」，三指标里最关心「共情」。

## 基础版公式
$$\textbf{选题} = \textbf{爽点} + \textbf{共鸣(YY)} + \textbf{故事壳}$$
- 三元缺一弱：有爽点没共鸣→难以代入；有爽点有共鸣没故事壳→无粘度、完不成充值。
- 爽点从五大爽点中选（见 `five-cool-points.md`），可叠加；共鸣把爽点落到生活困境（见 `resonance-and-shells.md`）；故事壳四选一（人物/目标/困境/奇遇，忌谜题）。

## 极简爽剧版（6.8）：想怎样 + 通过啥
$$\textbf{爽剧} = \textbf{想怎样} + \textbf{通过啥}$$

| 模块 | 本质 | 设计标准 |
|---|---|---|
| 想怎样 | 把抽象原始欲望落成具体 YY | 符合大多数人日常幻想；越具体越好（途径、对象、场景都具体）；要过瘾 |
| 通过啥 | 广义金手指（实现途径） | 相对合理 + 规则极简；一般不追求新创意 |

### 「想怎样」切入点清单（可补充，未穷尽）
两性（获取爱情）、离婚、发财、变强/升级、成为世界之王、改规则（换世界观）、名望、运气、暴力快感、复仇、正义执行、社会证明（打脸）。
- 质量标准：具体到「打谁的脸、怎么打、在哪打」，不空喊「我要爽」。

### 「通过啥」六类
道具/法器、外力辅助（高人相助）、传授、个人修炼/偶得秘籍、天赋觉醒、信息差（穿越/重生/预知未来）。
- **极简原则（完整保留）**：「通过啥」不是该大费笔墨的部分——它只是实现结果的理由。规则复杂、费解、限制条件多没有收益，观众是来过瘾的，不是来研究能力规则书的。
- 反例「时间静止」：合格版「我能让时间静止一分钟」；不合格版「能静止一分钟，但每天合计不超过三分钟；对方是女的就变 30 秒；白天月光下不能用……」——这些复杂规则毫无用处。
- 创意投放：金手指上**不硬创**，把心思放在「想怎样」的花式 YY 上。

### 一页填写模板
```
【想怎样】主欲望：____；对象：____；场景化爽点（≥3）：1.__ 2.__ 3.__
【通过啥】类型：道具/外力/传授/修炼·秘籍/觉醒/信息差/其他；规则（≤1–2句）：____
自检：能否删掉所有例外与限制后仍成立？□ 是
【合并】主角想 ____，通过 ____，从而 ____。
```

## 投稿实战版（5.1）：按号级选策略
| 类型 | 策略 | 说明 |
|---|---|---|
| 满级号（隐藏身份打脸） | 设**有创意的明确目标**（打脸只是伴随） | 「无双模型」已跑烂，纯复刻难卖；案例《六个姐姐》——下山帮六个姐姐解决不同困难，俗但目标明确 |
| 小号开挂 | 优先**开挂三型** | 更推荐，可不断换「以前做不到的事」防疲劳 |

### 小号开挂三型
| 型 | 定义 | 注意 |
|---|---|---|
| ① 单一具体金手指 | 预知未来、隐身等一项技能 | 具体、易共情、好写 |
| ② 集成型身份/道具 | 如「在世阎罗」→透视/断生死/鉴宝/隔空取物 | 更爽、变化多，但要有统一理由；注意封建迷信尺度 |
| ③ 重生 | 重生一周/十年 = 一种金手指（≠穿越） | 共情极强、男女通吃 |

- 开金手指理由不重要（触电、临死、关公附体、手机漏电都行）；观众迫切想开挂，理由随便。
- 十级后才开挂可以，但要用倒叙/前置把后面爽事提前给观众预判，别硬撑到十集才爽。

## 可执行清单
- 写下五要素：主爽点、YY 一句话、故事壳类型、想怎样、通过啥。
- GoldFingerMinimalGate：设定规则能否 30 秒/一句话说清？说不清就砍限制条件或换更简单的。
- 自检一句话能否说清「爽点」而非「壳」：满级号目标是否具体有微创意？小号三型选了哪型？
- 误判排查：有没有把末日/电竞/萌宝当「题材」？它们只是壳/元素，内核仍是开挂/爽点。

## 反模式
- 复杂世界观/复杂金手指开篇（把「通过啥」写成能力规则书）。
- 只有壳没有爽点（「全球电竞人人疯了，我建安全屋」本质仍是开挂囤货，不是电竞题材）。
- 死守单一赛道名、要求「别人没写过」（所有题材都烂大街，比的是微创意 + 台词剧情功力）。
- 金手指上死磕全新创意；或「想怎样」停在抽象欲望词。

## 与其他课差异（若有）
- 漫剧核心梗格式（100 字测试法、核心梗占 50%）以九格为权威（见 02-manju）；短剧选题公式以查理为本。
- 选题公式三版并存：基础版（爽点+共鸣+壳）用于拆解，实战版（满级/小号）用于投稿，极简版（想怎样+通过啥）用于快速起盘。
