# 场三件事·台词·悬念一加一
> 来源：查理短剧课 / 3.3–3.5、6.3
> 权威级别：P0
> 关联 Skills：scene.triple, prose.dialogue_formula, hook.suspense_design, scene.triangle, scene.opening8
> 关联 Agents：WritingOrchestrator

## 一句话
每场 = 交代信息 + 推进剧情 + 带来变化（缺一不可）；台词 = 态度 + 信息 + 潜台词；充值靠 To C 预期管理（悬念优先 + 「一加一」兑现）；防流水账用三角设计（目标→反义→逻辑回落→抵达目标）。

## 一、场：剧本的基本单位
### 场的定义
> 同一场景下连续时间内发生的所有事情 = 一场；或「同一场景 / 同一连续事件」的场面总和。

| 情况 | 是否拆场 |
|---|---|
| 教室上课 → 下楼球场打球 | 通常两场（换场景） |
| 追逐：大街→胡同→上车 | 一场（连续事件） |
| 教室打电话 → 走出走廊续聊 | 同场换景（同一事件） |
| 两人通话：切我这边 + 切对方家里 | 一场内可出现两个场景 |

操作原则：大部分按场景转换分场；连续事件换场景 → 不分场。

### 单场必须同时具备三个作用（SceneTripleGate）
| 作用 | 含义 |
|---|---|
| 交代信息 | 观众得到新信息 |
| 推进剧情 | 张力/期待往前拉 |
| 带来变化 | 场前后状态不同 |

三者须同时实现，缺一不可。只交代信息、剧情无变化 → 应合并或砍掉。验证标准：单场拿出来也有看点，**不依赖上下文也能打**（对短剧尤其关键，用户常因一个片段种草再看全片）。

### 场头格式（常加粗）
```
场号 | 场景 | 内/外 | 天时（日·夜·晨·昏）
```
正文三元素：环境（全面感知：视听味嗅触，吃戏常加深印象）、动作（脑子过画面）、对白。剧本 = 拍摄工作手册，不追求华丽修辞、少比喻。

### 编剧管 / 不管
| 可写 | 不要写（归导演/其他部门） |
|---|---|
| 画面感描述、角色表情（括号）、剧情内哼的歌 | 具体镜头运动/机位、演员走位、配乐选择 |

### 单场设计五步法（创作内心顺序）
```
① 确定单场任务 → ② 设计对抗（环境/对手/自身）→ ③ 围绕对抗制造具体事件
→ ④ 增加强度/烈度 → ⑤ 变化与反转
```
例「男主回家取奶奶遗物」：任务=取遗物；对抗=环境（没钥匙不开门）+对手（大舅哥堵门）+自身（翻窗踩猫尾）；烈度=雨滑爬不上/安探头/带人堵；变化=观众不能一眼看穿结局。第一反应往往强度不够，第四步专门加压。

### 小程序少换场（成本约束）
- 6–8 天拍约 200 分钟，换场最费时 → 省成本 = 少换场；全剧十来个场景就不错。
- 同场景连续多集时：仍按「单集 = 单场」处理，每集 1–2 分钟内完成小故事 + 起承转合 + 三作用；下一集虽同景，必须换「任务 + 对抗」，禁止同一任务同一种对抗连拖多集。

## 二、台词：态度 + 信息 + 潜台词
### 定位
视觉/行为优先于台词；对抗够烈时台词越少越好；台词 = 行为的补充。三条基本要求：简洁直接、行为固定时尽量少、说人话。

### 有效台词公式（完整保留）
```
有效台词 = 态度 + 信息 + 潜台词
            ↑前加     ↑你要表达的  ↑后加
```
| 零件 | 作用 |
|---|---|
| 信息 | 这句要传达的明确内容（先想清楚） |
| 态度 | 语气、称呼等，含进信息里 |
| 潜台词 | 第二层意思；单层易「干巴」 |

案例（赘婿回家取东西遇前丈母娘）：信息=不给你；态度=瞧不起；潜台词=「我女儿已改嫁，等新女婿打断你腿」。
- 无效：「滚，不给你。」
- 加厚示范：「你这个垃圾，只要我老太婆活着一天，你就别想把莎莎拿走。等我的新女婿回来，看他不打断你的腿。」（辱骂=态度；「休想拿走」=信息；「新女婿」=潜台词）

### 台词六项注意事项
| # | 注意 | 做法 |
|---|---|---|
| 1 | 不要长篇大论 | 信息精准、点到即可 |
| 2 | 不要问答陷阱 | 忌 A-B-A-B 相声模式，约连续十回合就破局 → 插动作或引入 NPC |
| 3 | 少打电话、少吃饭 | 静态戏缺动作、不流动 |
| 4 | 少解释、少回忆 | 「你为何五年不回家」往后倒/原地踏步；尽量压缩，勿放充值卡点集 |
| 5 | 少介词、少代词 | 「因为所以总而言之恰恰相反」不口语；「帮我拿杯水」别写「你帮我去拿杯水」 |
| 6 | 标点克制 | 小说式省略号/感叹号堆砌，演员没法「演三个点」 |

### 短剧台词四项适配（少换场 → 台词占比高，要扛更多信息）
1. **信息量更大**：更严格执行公式，常需概括、一步到位。
2. **概括性/偏舞台化**：「得罪他的人没有好下场」「在这城没人敢得罪他」——短剧篇幅不够时允许直接下结论。
3. **情绪推满**：生活 3/5/7 分，短剧常 8/9/10 分——恨到底、怕到底、爱得热烈。
4. **个性化更重要**：同景一堆人、服化道弱 → 主要靠台词区分性格。
   - 代入法：给每个角色找原型（流川枫/二舅/张飞），按原型说话快速拉开差异。
   - 表演法：每句大声念出来（默念无效），暴露不人话、别扭句。

### 旁白 / 独白 / 字幕
| 类型 | 短剧建议 |
|---|---|
| 旁白 | 可以用；高压缩、镜头场景有限时高效补信息 |
| 内心独白 | 可以用；创作者常忽略，实际很有用 |
| 出场字幕 | 可用；有的平台角色出场上字幕甚至是硬性要求（快速交代人设） |

## 三、预期管理与充值（3.5）
### To C 本质
充值短剧最重要环节是充值——让每一个真实用户发自内心愿意买单。传统影视是 To B（给平台打工），短剧是 To C（平地抠饼，直接讨用户喜欢）。预期管理 = 行为干预：管理预期 → 干预观看/消费行为 → 完播/上头 → 充值。

### 让观众上头两大方法
| 方法 | 本质 | 期待类型 | 特点 |
|---|---|---|---|
| 节奏快 | 信息密 + 情绪密 | 被动期待（无脑上头） | 粗暴有效，难持久、成本高 |
| 管理预期 | 升级包装信息与情绪 | 主动期待 | 有限场景/人物下更常用，本课重点 |

节奏分信息节奏（不断灌新信息）与情绪节奏（爽甜苏虐燃恐排布密）。约束：场景/角色有限，不能靠「飞机→撞车→悬崖→老虎」堆节奏，钱烧不起；多数情况主用方法二。

### 引发主动期待四手段（缺期待时依次考虑）
1. 新元素（新人物/新关系/新道具）
2. 变化（意外/转折）
3. 反转（隐藏或误导一个足以改变事物性质的重要元素，有**回味**：结合前情「原来早有伏笔」；纯意外只是变化）
4. **悬念（★ 最重要）**：让观众产生悬而未决的念想。

### 好悬念四属性
| 属性 | 含义 |
|---|---|
| 参与感 | 观众足够关心，放在主角主行动线/主目标/主人物关系上 |
| 未知 | 不知道会怎样，心才悬着 |
| 可能性 | 给线索/方向/选项，让观众愿意猜（「弟弟临死给线索→锁定两三个嫌犯」才有可能性） |
| 压迫感 | 关乎重大（「左轮转盘有没有子弹」有压迫；「长粉笔短粉笔」无） |

### 制造悬念的三种信息不对称
| 类型 | 信息关系 | 效果 | 推荐度 |
|---|---|---|---|
| ① 观众 > 角色 | 观众多知 | 炸弹理论：观众着急 | ★ 强烈推荐 |
| ② 观众 < 角色 | 角色多知 | 观众揪心「到底咋回事」 | ★ 强烈推荐 |
| ③ 观众 = 角色 | 同步一头雾水 | 可猜空间小、劲小 | 可用但最不推荐 |

想强期待、强充值卡点 → 优先练熟 ①②，③ 酌情用。悬念贯穿期一次只揣一件事（见 revise20 法则 6）。

### 兑现与「一加一」原则
- 兑现 = 情绪释放那一下 ≈ 爽点落地；不兑现（气走、不打脸）= 没有爽点。
- **一**：必须兑现观众已形成的预期（爽点）；**加一**：兑现同时再加一个惊喜/变化。
- 例（奢侈品店打脸）：预期=店员嘲「买不起」→ 主角买下所有羽绒服打脸（一）；加一=全部送到立交桥下给流浪汉一人一件：「顶奢？让乞丐穿」。避免 100 集只重复同一种兑现导致疲劳。

## 四、防流水账：三角设计（6.3）
### 公式
```
① 定位目标（这场要表达什么）→ ② 先往「反义词」方向设计剧情（铺垫反差）
→ ③ 再走直线/逻辑剧情（事件推进）→ ④ 拐回目标（情绪/信息落地）
```
### 案例库（吃透结构，不抄情节）
| 案例 | 目标 | 反义 | 回落 |
|---|---|---|---|
| 《Hello！树先生》 | 没地位 | 先写别人尊敬：叫树哥、请吃饭 | 席间没发言权，多说一句挨巴掌 |
| 外卖单亲父女 | 可怜 | 先写坚强懂事：帮送外卖、像小顶梁柱 | 生日被忘，搞坏别人蛋糕 → 可怜落地 |
| 《当幸福来敲门》 | 无家可归惨 | 用做游戏化解：假设有怪物找地方躲 | 躲进公厕，清洁工敲门不敢吭声 → 崩溃 |
| 写「穷」 | 穷 | 先写「装大方」 | 被现实打回/被戳破 |

归纳：要写穷 → 先写大方；要写没地位 → 先写被尊敬；要写可怜 → 先写坚强/快乐。反例（直线硬刚）：「男主被欺负」直接三流氓围殴逼吃屎——劲大但廉价、缺层次。短剧酌情使用，忌每场都绕。

## 五、开场方向（标题称 8，录音展开 7，待核实）
| # | 开场 | 核心动作 | 适配 | 慎用提示 |
|---|---|---|---|---|
| 1 | 环境开场 | 交代时空与社会规则 | 高 | — |
| 2 | 技能开场（炫技） | 先炫主角主技能 | 高（短剧常见） | — |
| 3 | 人物共情开场 | 先立可怜/可信/可爱 | 高（锁视角） | — |
| 4 | 激励开场 | 先抛大难题/大诱惑/被迫出门原因 | 高（入戏快） | 环境人物一目了然时更适用 |
| 5 | 动作开场 | 二话不说先打 | 中 | 老师不推荐纯动作开场 |
| 6 | 悬念开场 | 把中后段标志场捞到开头 | 中高 | 勿生生造谜题 |
| 7 | 回忆开场 | 从过去捞一场有用前史 | 中 | 慎用；无用前史勿写 |

- 动作开场必须绑定意义（动作=技能炫技，或=激励事件），纯动作慎用。
- 悬念开场 = 捞后面一场戏到开头让观众暂时看不懂，不是凭空造谜。
- 短剧优先：技能、共情、激励、环境；动作/回忆降权。

## 可执行清单
- 写场前三问：交代什么信息、推进什么剧情、带来什么变化。
- 台词过：删纯寒暄；每句检查态度+信息+潜台词；大声念一遍。
- 悬念自检四属性（参与感/未知/可能性/压迫感）；优先信息不对称①②。
- 兑现必做 + 一加一；每集结尾留钩子。
- 流水账时套三角（目标→反义→逻辑→回目标）；开场卡住从 7 种里选一种。

## 反模式
- 场只聊天不推进（纯留白/纯情绪，无信息无变化）。
- 悬念过多并行（贯穿期一次只揣一件事）。
- 把纯意外当反转（反转必须有隐藏/误导 + 回味）。
- 台词 A-B-A-B 相声模式、静态电话饭局、解释回忆占充值点、虚词代词、小说标点。
- 每场都绕三角、不直接不爽（三角是工具，服务通俗与爽感）。
