# 共鸣 YY 与故事壳
> 来源：查理短剧课 / 2.3、2.4
> 权威级别：P0
> 关联 Skills：topic.resonance_yy, topic.story_shell
> 关联 Agents：CoreHookAgent

## 一句话
共鸣 = 把五大爽点落实到日常生活困境里的「YY」（爽点 × 困境）；故事壳四选一（人物/目标/困境/奇遇），谜题导向默认否——它会把观众从感性爽感拉回理性思考，不利充值。

## 共鸣点 = YY 点
> YY = 把人类共通的五种爽点，落实在日常生活困境之中。

- 生活是苦旅，人人都有困境（事业高歌猛进、特别忙的人花在 YY 上的时间更少，通常不是充值主力）。
- 充值短剧主力 ≈ **强 YY 人群** ≈ 生活困境相对更多的人。
- 寻找共鸣的方法：基于五大爽点，匹配目标用户的困境与幻想解法。
- YY 不是空喊爽，是可代入的欲望场景——落到「对象 + 途径 + 场景」。

## 用五大爽点重新看「赛道」
| 爽点 | 对应题材/赛道 |
|---|---|
| 两性 | 离婚、赘婿、霸总；女频穿越王子/保镖/三哥哥宠上天 |
| 征服 | 都市战王、天生神力、绝世武功、一夜暴富、金手指开挂、穿越去征服 |
| 优势 | 权力/官场、阶层、神医（看穿别人还能活几年）、家族系统 |
| 归属 | 黑帮、修仙门派等「你到底属于哪一类」 |
| 秩序 | 复仇、打脸、善恶有报、翻身文、重生 |

## 爽点叠加的「全家桶」开局
高充值典型开局常一口气叠四种：
1. 离婚/赘婿（两性困境）
2. 实则龙王/战王（征服）
3. 城市有阶层：战王第一层、商界第二、女主家庭第三（归属）
4. 回来报仇、伸张正义（秩序）

> 爽点不怕综合利用；硬把自己界定成「只写离婚剧」反而限制爆发力。爆款难被单一赛道标签框住，是正常现象。

## 男女频幻想路径（YY 的性别差）
同一个人可同时需要多种爽点；但性别与年龄影响幻想路径，投放也要求人群精准。

| | 男性更倾向 | 女性更倾向 |
|---|---|---|
| 解法路径 | 自己拥有力量：自己是战王、一夜暴富 | 先获得一份爱：哥哥保护、穿越来的武林高手当保镖/公主 |

金手指开挂男女都有；差别只在「能力挂自己身上」还是「挂身边男性身上」。

## 故事壳：五选四（忌谜题）
「导向」= 观众靠什么入戏、靠什么产生长期期待。

| 类型 | 入戏方式 | 短剧 |
|---|---|---|
| 人物导向 | 这人太特别（战王、龙王、神医、透视眼） | ✅ |
| 目标导向 | 要去干成某事（报仇、发财、寻宝） | ✅ |
| 困境导向 | 陷入大麻烦（末日、被困、被追杀） | ✅ |
| 奇遇导向 | 穿越/重生/获得金手指 | ✅ |
| 谜题导向 | 这到底怎么回事/谁干的（阿加莎式悬疑） | ❌ |

### 为什么不用谜题导向
| 维度 | 爽感 | 谜题/思考 |
|---|---|---|
| 脑机制 | 深层脑、感性 | 表层脑、逻辑思维 |
| 产品目标 | 保持上头、继续充值 | 一旦理性启动，容易觉得「好像有点贵」 |

原则：**不要让观众在理性思考与感性爽感之间来回横跳**。短剧应尽量让大脑停留在爽感层。未来付费变轻后可能出现迷局类短剧，但当前重付费形态不推荐。

## 选题操作闭环（SOP）
```
1. 明确目标用户（性别、年龄层、主要生活困境）
2. 从五大爽点中选取并叠加（两性/征服/优势/归属/秩序）
3. 把爽点落到具体困境 → 形成 YY/共鸣点
4. 选择一种故事壳（人物/目标/困境/奇遇）
5. 进入剧本写作
```
- 照着小说网站某条赛道写是捷径，但要知道「为什么」；真正稳定的方法是「爽点 + 共鸣」逻辑，不是背赛道名。

## 可执行清单
- 一句话测试：把选题转述给路人，问「想不想追更」——说不清爽点或没共鸣，回炉。
- PuzzleShellGate：若选了谜题壳，必须有强理由（否则拦截）；默认改用前四壳。
- 写清「困境 → 爽点解法」：目标用户卡在哪，用什么爽点替他 YY。
- 男女频检查：主角的幻想路径是否对（男自己动手/女借势获爱）。

## 反模式
- 壳选谜题却无充值钩，把观众拉回理性。
- YY 小众到无法投放（幻想太小众、难共鸣）。
- 只叠爽点不落困境（没有「痛」就没有「解压」的对比）。
- 死守单一赛道名，不敢做爽点全家桶。
