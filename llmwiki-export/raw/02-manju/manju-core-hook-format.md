# 漫剧核心梗输出格式
> 来源：九格 / ai漫剧写作流程和方法.md
> 权威级别：P0
> 关联 Skills：manju.core_hook
> 关联 Agents：CoreHookAgent, CoreHookCriticAgent

## 一句话
核心梗必须带标题钩、核心叙述、标签、动机、危机、开篇结构，才能进入大纲阶段。

## 核心要点（条目）
- 标题钩示例形态：身份反差+金手指画面感一句话。
- 核心梗：穿越/身份+危机+反转能力+事业/复仇线。
- 开篇结构常用：男主自述+配角危机+配角震惊+小弟/能力登场。
- 标签服务投放与检索，勿堆无关词。
- 进阶：人设微创新 + 逻辑自洽。

## 可执行清单 / 模板
- 字段齐全检查表：title_hook / core_hook / tags / motivation / crisis / opening_structure / opening_beats
- 画面测试：能否用 3 个分镜讲清开篇。

## 反模式
- 只有世界观介绍无人设危机。
- 金手指规则说不清或过复杂。

## 与其他课差异（若有）
- 无显著冲突；按权威源原则引用。
