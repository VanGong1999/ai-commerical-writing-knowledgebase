# 品牌故事五种正面模式
> 来源：北大博士教你故事变现 / 第 13 课（讲师刘六六）
> 权威级别：P2
> 关联 Skills：—
> 关联 Agents：WritingOrchestrator

## 一句话
构建品牌 = 把自己当作品、别人当读者；用「斩妖除魔 / 白手成家 / 一路追寻 / 远行归来 / 重生」五种正面情节模式组织品牌叙事，建立信任。

## 品牌叙事的本质
- 核心态度：**把自己当作品，别人当读者**。
- 品牌故事不是吹牛，是用**正面情节模式**让受众认同、信任、追随。
- 与哈佛「故事 = 建立信任（催产素）」同源：正面模式是「唤起积极情绪 → 建信任 → 促行动」的具体载体。

## 五种正面情节模式
| 模式 | 叙事内核 | 适用场景 |
|---|---|---|
| **斩妖除魔** | 战胜外部敌人 / 障碍，守护所珍视之物 | 挑战行业乱象、对标竞品、维权 |
| **白手成家** | 从一无所有到建立事业 | 创始人 / 创业者故事 |
| **一路追寻** | 为理想 / 目标持续求索 | 匠人、研发、长期主义品牌 |
| **远行归来** | 走出去历练，带本领回归 | 转型、跨界、留学归国创业 |
| **重生** | 遭遇失败 / 低谷后蜕变新生 | 翻盘、二次创业、逆袭 |

## 与哈佛公共叙事三段论的结合
品牌故事可用「正面模式」定主线，再用公共叙事三段论填充血肉：
```
Self（我的故事）：我是谁、为什么在乎、为什么有能力
Us（我们的故事）：我们是什么团体、共同传统与挑战
Now（眼下的故事）：为什么现在必须行动、希望大吗、做什么
```
- 模式选定后，把 Self / Us / Now 三段分别落到同一模式框架里，避免叙事割裂。

## 模式选择建议
- 先看「主角真实经历」最接近哪种模式（真实是信任前提，别硬套）。
- 再看「目标受众」最容易被哪种模式唤起积极情绪（紧迫 / 义愤 / 希望 / 归属）。
- 单一主线贯穿到底，不混用多种模式（人设不能崩）。

## 可执行清单
- 选一个正面模式 → 用 Self / Us / Now 各写一段 → 结尾加一个明确行动号召。
- 自检：模式是否正面（利于建信任而非消耗信任）？三段是否同属一个主线？
- 把「努力过程 / 试炼」写足，不只晒成就（呼应哈佛英雄之路重过程）。

## 反模式
- 用负面 / 消耗信任的故事当主线（卖惨无建设、攻击无守护对象）。
- 模式混用、人设崩坏。
- 只讲「我多厉害」（Self 不真诚），不讲 Us / Now。
- 只讲糟糕不给希望（Now 的坑）。
